# 📖 AudioService 주요 코드 주석 가이드

학생 여러분, 실제 실무 코드를 보면서 각 라인이 어떤 역할을 하는지 함께 살펴봅시다! 👨‍🏫

## 1. 오디오 엔진 잠금 해제 (`unlockAudio`)
모바일 웹 환경에서 오디오 재생을 가능하게 만드는 필수 관문입니다.

```typescript
async unlockAudio() {
  // 이미 잠금 해제되었다면 다시 하지 않음
  if (this.isUnlocked && this.audioContext?.state === 'running') return;

  try {
    // 1. AudioContext 생성 및 활성화 (브라우저 오디오 시스템의 기본 토대)
    const AudioContextClass = (window.AudioContext || (window as any).webkitAudioContext);
    if (AudioContextClass) {
      this.audioContext = new AudioContextClass();
      await this.audioContext.resume(); // 정지 상태인 컨텍스트를 흔들어 깨움

      // 2. 무음 오실레이터 재생 (엔진에 신호를 줌)
      const oscillator = this.audioContext.createOscillator();
      const gainNode = this.audioContext.createGain();
      gainNode.gain.value = 0.0001; // 아주 작아서 들리지 않는 소리
      oscillator.connect(gainNode);
      gainNode.connect(this.audioContext.destination);
      oscillator.start(0);
      oscillator.stop(0.1);
    }

    // 3. 빈 말하기(Empty Speech) 시도하여 TTS 엔진 잠금 해제
    const utterance = new SpeechSynthesisUtterance(' ');
    utterance.volume = 0;
    this.synthesis.speak(utterance);

    this.isUnlocked = true; // 이제 소리를 낼 준비가 완료됨!
  } catch (e) {
    console.error('오디오 엔진 잠금 해제 실패:', e);
  }
}
```

## 2. 문장 단위 재생 로직 (`playNextSentence`)
긴 텍스트를 한꺼번에 읽으면 멈출 위험이 커집니다. 그래서 우리는 문장 단위로 쪼개서 읽습니다.

```typescript
private playNextSentence(language: string, rate: number, skipIncrement: boolean = false) {
  // 더 읽을 문장이 없으면 종료 처리
  if (!this.isSentenceMode || this.sentenceIndex >= this.sentences.length) {
    this.isSentenceMode = false;
    this.onSentenceEnd?.();
    return;
  }

  const sentence = this.sentences[this.sentenceIndex]; // 현재 읽을 문장 가져오기
  this.currentUtterance = new SpeechSynthesisUtterance(sentence);
  
  // 음성 엔진에 문장이 끝났을 때의 행동을 예약 (재귀적 호출)
  this.currentUtterance.onend = () => {
    if (!skipIncrement) this.sentenceIndex++; // 다음 문장으로 인덱스 증가
    
    // 150ms의 아주 짧은 휴식 후 다음 문장 재생 (자연스러운 연결)
    this.playbackTimer = setTimeout(() => {
      this.playNextSentence(language, rate);
    }, 150);
  };

  this.synthesis.speak(this.currentUtterance); // 목소리 출력!
}
```

## 💡 학습 포인트
-   **비동기 처리**: `setTimeout`과 `Promise`를 적재적소에 사용하여 오디오가 메인 스레드를 방해하지 않게 합니다.
-   **상태 관리**: `isSentenceMode`, `sentenceIndex` 등의 변수를 통해 현재 어디를 읽고 있는지 정확히 추적합니다.
