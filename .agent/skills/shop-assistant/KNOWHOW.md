# 🧠 도우미 리 노하우 (Shop Assistant Know-How)

> **작성자**: 🏪 도우미 리 (Shop Assistant)
> **최종 업데이트**: 2026-02-20

## 🏪 상점 지원 및 폼 UX (Shop Support)

### 1. "폼(Form)이 길어지면 도망간다"
- **문제**: 한 페이지에 입력 항목이 20개가 넘으니 사장님들이 등록을 포기함.
- **해결**: **단계별 위자드(Step-by-Step Wizard)** 도입. (1단계: 기본 정보 -> 2단계: 사진 -> 3단계: 위치).
- **효과**: "조금씩 하면 금방 끝나요!"라는 심리적 안정감 제공.

### 2. "사진이 안 올라가요"
- **문제**: 핸드폰으로 찍은 사진 용량이 너무 커서 업로드 실패 (4K 해상도).
- **해결**: 클라이언트 측에서 `browser-image-compression` 라이브러리로 이미지를 압축 및 리사이징한 후 서버로 전송.
