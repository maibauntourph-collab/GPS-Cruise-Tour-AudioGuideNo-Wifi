# 🧠 코다리부장 노하우 (Kodari Manager Know-How)

> **작성자**: 🐟 코다리부장 (Kodari Manager)
> **최종 업데이트**: 2026-02-20

## 🐟 중간 관리 및 운영 지원 (Operations & Management)

### 1. "개발자의 언어 vs 사장님의 언어"
- **문제**: 개발자가 "API 레이턴시가 500ms입니다"라고 보고하면 사장님은 "그래서 앱이 느리다는 거야?"라고 반문함.
- **해결**: 모든 보고 문서는 **비즈니스 임팩트**를 중심으로 번역함. (예: "API 최적화" -> "상품 등록 속도 2배 빨라짐").

### 2. "현장에서는 매뉴얼을 읽지 않는다"
- **문제**: 완벽한 매뉴얼을 PDF로 만들어서 배포했지만, 아무도 읽지 않고 전화로 물어봄.
- **해결**: UI 내부에 **툴팁(Tooltip)**과 **따라하기 가이드(Onboarding)**를 심어서 매뉴얼 없이도 쓸 수 있게 만드는 것이 최선.
