## 1. 📂 기술 아키텍처 제안 (V2 Architecture)

버전 2의 다양한 테마를 수용하기 위해 다음과 같은 확장성 있는 스택을 제안합니다.

- **Backend**: **Hono + Cloudflare Workers** (전 세계 성지 및 관광지 어디서나 빠른 응답성 확보)
- **Database**: **NeonDB** (컨셉별 메타데이터 및 유저 취향 태그 관리)
- **AI Engine**: **Gemini 2.0 Flash** (사용자의 사진과 투어 컨셉을 실시간으로 분석하여 커스텀 오디오 생성)
- **Sync**: **Magic Photo Sync** (EXIF 데이터를 활용한 타임라인 자동 생성)

## 2. 🏛️ 컨셉별 테마 및 핵심 기능 아이디어

사용자가 선택한 모드에 따라 UI/UX와 오디오 가이드의 성격이 완전히 변화합니다.

### A. 종교 및 영적 탐구 (Spirituality)
| 컨셉 | 핵심 기능 (Soul Feature) | 오디오 톤앤매너 |
| :--- | :--- | :--- |
| **성지순례** | GPS 기반 기도/묵상 자동 재생 | 경건하고 차분한 낭독톤 |
| **불교투어** | 사찰 접근 시 1분 명상 가이드 | 낮은 저음의 평온한 톤 |
| **천주교투어** | 성당 내부 스테인드글라스 도슨트 | 울림이 있는 성당 내부 톤 |
| **이슬람투어** | 기도 시간(Salat) 알림 및 메카 방향 표시 | 정보 전달 위주의 전문적 톤 |
| **기독교투어** | 성경 속 지명과 현재 위치의 연결 | 스토리 중심의 감동적인 톤 |

### B. 전문 분야 및 취향 (Pro-Interest)
- **역사투어 (설민석 스타일)**: **"드라마틱 역사 도슨트"** 
    - **핵심 기능**: "이곳은 말이죠! 여러분!"으로 시작하는 흡입력 있는 스토리텔링 제공. GPS 좌표에 맞춰 당시의 긴박했던 역사적 사건을 1인칭 시점으로 재구성하여 들려줌.
    - **AI 큐레이션**: 사용자가 명소를 찍으면 설민석 선생 특유의 말투로 "이게 왜 대단하냐면요~"라며 역사적 의미를 1분 요약 해설.
- **와인투어**: **"디지털 소믈리에"** - 방문한 양조장의 와인 목록을 체크하고 개인 취향 저장.
- **명품쇼핑투어**: **"VIP 컨시어지"** - 브랜드별 면세 한도 계산 및 실시간 웨이팅 현황 공유.
- **기업탐방투어**: **"비즈니스 인사이트"** - 해당 기업의 산업적 위치와 성공 전략 리포트 제공.

### C. 동반자 및 정체성 (Identity)
- **팀/기업연수**: **"투어 미션 임파서블"** - 팀원들이 특정 장소에서 퀴즈를 풀어야 다음 경로 오픈.
- **가족투어**: **"세대별 맞춤 도슨트"** - 아이들에게는 동화로, 부모님에게는 추억의 음악과 함께.
- **연인투어**: **"러브 타임라인"** - 같은 장소에서 마주 본 사진을 찍도록 유도하여 합성 기능 제공.
- **싱글족/여성/남성을 위한**: **"세이프 커뮤니티"** - 혼자 여행해도 안전한 경로와 현지 신뢰할 수 있는 장소 우선 배치.

## 3. 📸 매직 포토 동기화 고도화 (V2 Special)

- **컨셉 매칭 필터**: 성지순례 사진은 경건한 필터로, 쇼핑 사진은 화려한 보정으로 자동 적용.
- **스마트 앨범**: 투어가 끝나는 순간, 선택한 컨셉의 배경 음악이 깔린 짧은 요약 영상(Reel) 자동 생성.
