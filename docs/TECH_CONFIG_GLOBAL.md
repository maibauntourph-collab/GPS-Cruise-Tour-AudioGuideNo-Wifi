# 🌎 글로벌 사용자(EN/JA/TW)를 위한 개인화 서비스 기술 구성 가이드

학생 여러분, 안녕하십니까! 전 세계 여행객들이 내 집처럼 편안하게 여행할 수 있도록 돕는 우리 서비스의 글로벌 기술 아키텍처를 소개합니다. 👨‍🏫

## 1. 지능형 국적 감지 및 지역화 (Smart Region Detection) 📡
사용자의 기기 설정과 언어를 분석하여, 가장 적합한 콘텐츠를 즉각적으로 보여주는 것이 우리 서비스의 첫 번째 기술입니다.
- **Navigator Region API**: `navigator.languages`와 브라우저 타임존 정보를 조합하여 미국, 일본, 대만, 동남아 등 주요 권역을 0.1초 내로 판별합니다.
- **자동 언어 전환**: 판별된 국적에 따라 UI 전체(한국어, 영어, 일본어, 중국어 번역)가 자동으로 최적화됩니다.

## 2. "PICK ✨" 배지 기반의 국가별 개인화 (Personalized Curation) 💎
수백 개의 여행지 중 나에게 맞는 목적지를 찾는 것은 어려운 일이죠. 우리는 국가별 선호 데이터를 통해 이를 해결했습니다.
- **국가별 인기 선호도(DB Tags)**: 각 랜드마크 데이터에 `targetNations` 태그를 삽입하여, 해당 국적 사용자가 가장 좋아하는 명소(예: 미국인에게는 설악산, 일본인에게는 인사동)에 "US PICK ✨" 등의 시각적 배지를 노출합니다.
- **동적 정렬 알고리즘**: 내 국적 사용자들이 특히 선호하는 장소가 투어 리스트 최상단에 자동 배치되어 빠른 의사결정을 돕습니다.

## 3. 다국어 지능형 AI 가이드 (Multi-Lingual AI Engine) 🤖
단순한 기계 번역이 아닌, 각 언어권의 감성을 담은 투어 추천을 제공합니다.
- **Gemini 2.0 & GPT-4o 통합**: 사용자의 국적 정보를 AI 엔진에 전달하여, 해당 국가 사용자가 선호하는 장소를 최우선으로 투어 루트에 포함하는 '지능형 일정 생성'을 수행합니다.
- **Story Teller Lee 🎙️**: 각 장소의 역사와 배경지식을 각 나라의 정서에 맞는 유려한 나레이션으로 번역하여 제공합니다.

## 4. 오프라인 모드 및 PWA (No-Wifi PWA Strategy) 📲
인터넷이 터지지 않는 낯선 곳에서도 여행은 계속되어야 합니다.
- **강력한 캐싱 시스템**: 한 번의 '오프라인 준비' 버튼 클릭으로 모든 지도 타일, 이미지, 오디오 가이드가 기기에 영구 저장됩니다.
- **PWA 최적화**: 웹 앱을 설치형 앱처럼 사용하여 홈 화면에 추가하고, 비행기 모드에서도 모든 오디오 가이드를 청취할 수 있습니다.

## 5. 글로벌 커머스 연동 (Global Booking Sync) 🎫
- **다국적 플랫폼 통합**: Klook, GetYourGuide, CatchTable 등 글로벌 예약 사이트를 각 나라 언어에 맞춰 직접 연결하여 최저가 예약을 지원합니다.
