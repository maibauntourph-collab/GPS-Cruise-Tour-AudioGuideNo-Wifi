## 💾 2. 데이터 전략 및 동기화 (Data & Sync Strategy)

### 하이브리드 온디맨드(On-Demand) 동기화
- **프롬프트**: "QR 설치 시 용량을 최소화(Index Only)하고, 사용자가 도시를 조회할 때만 NeonDB 데이터를 로컬(IndexedDB)로 캐싱하는 하이브리드 동기화 시스템을 구축해줘." (업데이트: 2026-02-23 18:43)
- **추천 에이전트**: `Query Master`, `Automation Doctor`
- **핵심 목표**: 초기 앱 배포 사이즈 80% 이상 절감 및 오프라인 서바이벌.

### 이미지 리사이징 및 용량 최적화 (Image Proxy)
- **프롬프트**: "NeonDB의 원본 이미지가 너무 클 경우, Cloudflare Images를 활용해 리사이징하여 로컬 저장 용량을 최적화하고 데이터 사용량을 최소화하는 로직을 제안해줘." (업데이트: 2026-02-23 18:43)
- **핵심 목표**: 모바일 저장 공간 및 네트워크 비용 최적화.

### 데이터 무결성 및 자동 백업
- **프롬프트**: "매일 새벽 3시에 DB를 자동 백업하고, 장소 카테고리의 '이색' 키워드를 분석해 실시간 통계를 산출하는 자동화 스케줄러(Cloudflare Cron)를 작성해줘." (업데이트: 2026-02-23 18:43)
- **핵심 목표**: 관리 자동화 및 데이터 신뢰성 확보.

## 🎨 3. 프리미엄 UI/UX 및 디자인 (Premium Design)

### Glassmorphism 및 히어로 이미지 생성
- **프롬프트**: "인트로 페이지 버튼들을 거대한 유리 질감(Glassmorphism) 카드로 교체하고, 세부(Cebu)의 히어로 배경 이미지를 `generate_image`로 새로 생성해서 적용해줘." (업데이트: 2026-02-23 18:43)
- **추천 에이전트**: `Designer Kim`
- **핵심 목표**: 프리미엄 브랜드 이미지 구축.

### 랜드마크 상세 다이얼로그 고도화
- **프롬프트**: "상세 페이지 레이블을 감각적인 용어로 변경하고, 오디오 가이드에 '일시정지/재개' 및 '처음부터 듣기' 기능을 추가하여 UX를 극대화해줘." (업데이트: 2026-02-23 18:43)
- **핵심 목표**: 전문적인 인터랙션 제공.

### 카드 사이즈 옵티마이즈 (Card Size Optimization)
- **프롬프트**: "모바일에서 `UnifiedFloatingCard`의 탭 리스트가 잘리지 않도록 고정 그리드를 제거하고 유연한 레이아웃을 적용해줘. 특히 'Overview' 탭 선택 시 가독성을 위해 너비를 유연하게 조정해줘." (업데이트: 2026-02-23 20:10)
- **주요 성과**:
    1. **탭 레이아웃 최적화**: 모바일에서 글자가 잘리던 현상을 해결하기 위해 고정 그리드를 제거하고, 유연하게 가로로 흐르는 탭 시스템을 도입했습니다. 텍스트 크기도 기기에 맞춰 자동으로 최적화됩니다.
    2. **반응형 너비 적용**: 'Overview' 탭 활성화 시 모바일 뷰포트에 최적화된 너비(`calc(100vw-48px)`)를 적용하여 텍스트 가독성을 극대화했습니다.
    3. **프리미엄 프레임**: 한층 깊어진 입체적인 그림자와 고급스러운 유리 질감(Glassmorphism)을 적용하여, 앱의 첫인상이 더욱 품격 있게 변했습니다.

## 🔧 5. 시스템 안정성 및 유지보수 (Quality Control)

### 오디오 로그 제어 및 에러 핸들링 보강
- **프롬프트**: "콘솔에 과도하게 출력되는 오디오 관련 로그들을 100% 억제하고, 오디오 서비스 실패 시에도 UI가 먹통이 되지 않도록 에러 핸들링을 완벽히 보강해줘." (업데이트: 2026-02-23 18:43)
- **핵심 목표**: 런타임 성능 및 안정성 확보.

### 오디오 재생 및 일시중지 안정화 (Bug Doctor)
- **프롬프트**: "일시정지 후 재개 시 소리가 나오지 않는 문제를 해결하기 위해 Force Resume 폴백 로직을 구현하고, AudioContext 싱글톤 관리로 브라우저 보안 정책(Autoplay)을 완벽히 통과하게 해줘." (업데이트: 2026-02-23 20:10)
- **주요 성과**:
    1. **고도화된 Force Resume**: 재개 명령이 무시될 경우 현재 문장부터 자동 재시작하며, Clova/OpenAI 등 외부 TTS 모드에서도 작동하도록 폴백 로직을 세분화했습니다.
    2. **보안 정책 대응**: 사용자 제스처 동기화 및 AudioContext 활성화 로직 고도화.
    3. **언어 매칭 정규화 (Normalization)**: 브라우저별 상이한 언어 코드 관례(`ko_KR`, `KO-KR` 등)를 통합 매칭하여 한국어 음성 누락 방지.
    4. **상세 디버깅 강화**: 음성 선택 시 이름, 언어, 점수를 기록하여 추적성 확보.

### 인코딩 복구 및 데이터 정제 (완료)
- **프롬프트**: "Home.tsx와 translations.ts에 남은 모든 한글 인코딩 깨짐(?꾩갑吏€ 등)을 전수 조사해 복구하고, 좌표가 0,0인 부실 데이터를 리스트업하는 cleanup 스크립트를 실행해줘." (업데이트: 2026-02-23 18:43)
- **핵심 목표**: 시각적/데이터 무결성 100% 달성.
