> "학생 여러분, 개인용 앱을 넘어 B2B 시장으로 확장하는 것은 비즈니스 모델의 완성입니다. 차량의 인프라(WiFi, Navi)와 우리 앱의 콘텐츠를 결합하여, 단체 관광객 속에서도 개인별 맞춤 언어 가이드를 제공하는 '스마트 모빌리티 투어'를 실현합시다."

---

## 1. 🛠️ B2B 핵심 시스템 구조 (System Architecture)

차량 내부 인프라를 활용하여 **데이터 소모 없이** 고품질 가이드를 제공하는 구조입니다.

- **Sync**: 차량 네비게이션 API ↔ 앱 실시간 위치 동기화.
- **Access**: 차량 좌석별 **QR 코드** 스캔을 통한 즉시 접속.
- **Network**: 차량 전용 전용 **로컬 WiFi** 망을 통한 오디오 스트리밍 (오프라인 모드 극대화).
- **Personalization**: 동일한 버스 안에서도 국적별로 자신의 스마트폰에서 개인 언어(개인 이어폰)로 청취.

---

## 2. 🚛 주요 적용 분야 (Business Areas)

### A. 투어 버스 & 여행사 (Travel Agency)
- **단체 가이드 방송 대체**: 가이드가 마이크로 방송하는 대신, 승객 개개인이 앱을 통해 고화질 사진과 함께 상세 설명을 자신의 언어로 청취.
- **경로 최적화**: 여행사 관리자 웹에서 투어 순서를 변경하면 차량 네비게이션과 승객 앱에 실시간 반영.

### B. 택시 & 차량 공유 (Taxi/Ride-Hailing)
- **프라이빗 도슨트**: 택시 이동 중 창밖 명소에 대한 오디오 가이드 자동 실행.
- **결제 연동**: 투어 종료 후 앱 내에서 택시비 및 투어 팁 결제 통합.

### C. 자가 운전자 (Car Navigation)
- **인카(In-Car) 인포테인먼트**: Android Auto / Apple CarPlay 연동을 통해 차량 스피커로 오디오 가이드 송출.

---

## 3. 📲 사용자 시나리오 (User Scenario)

1.  **QR 스캔**: 승객이 좌석 앞 QR 코드를 스캔합니다.
2.  **자동 연결**: 차량 내부 WiFi에 자동 접속되며, 현재 차량의 네비게이션 위치와 앱이 동기화됩니다.
3.  **개인 안내**: 차량이 특정 랜드마크를 지날 때, 승객의 스마트폰에서 설정된 언어로 안내 방송이 나옵니다.
4.  **멀티미디어**: 안내 방송과 동시에 차량 내 디스플레이(또는 개인 폰)에 명소의 내부 사진과 관련 영상이 팝업됩니다.

---

## 4. 🚀 V1 기획 반영 사항

- **B2B 전용 로그인 모드**: 기사/가이드용 관리자 인터페이스 추가.
- **WiFi-Direct 스트리밍**: 서버 연결 없이 로컬 환경에서 대용량 오디오/이미지 전송 최적화.
- **네비게이션 위젯**: 타 앱(T-map, Google Maps) 위에 오버레이로 정보를 띄우는 플로팅 위젯 개발.
