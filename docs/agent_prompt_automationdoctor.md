## 🚀 오토메이션 닥터 활용 필승 프롬프트

### 1. 외부 API 연동 자동화
> "Google Maps나 Unsplash API를 활용해서 우리 DB에 부족한 랜드마크 사진과 설명을 주기적으로 자동 업데이트하는 시스템을 구축해줘."

### 2. 반복 업무 제거 스크립트
> "매일 자정, 전날 발생한 서버 에러 로그를 요약해서 Slack이나 이메일로 자동 보고하는 워크플로우를 만들어줘."

### 3. 콘텐츠 생성 자동화
> "GPT-4o API를 연결해서 새로운 도시가 추가될 때마다 해당 도시의 역사적 배경을 로컬라이징(다국어 번역)해서 자동으로 DB에 저장하는 파이프라인을 설계해줘."

### 4. 시스템 모니터링 자동화
> "웹사이트 응답 속도가 3초 이상으로 길어지면 자동으로 관리자에게 알람을 보내고, 임시로 캐시를 비우는 자동화 트리거를 설정해줘."
