# 🚀 데이터 시뮬레이션 및 백업 고도화 계획

교수님, 요청하신 **'시뮬레이션 시 실시간 데이터 동기화'**와 **'Neon DB 백업 클러스터 구축'**을 위한 구체적인 실행 계획입니다. 🎓

## 1. 실시간 데이터 브릿지 (Neon -> Local)
사용자가 특정 나라로 시뮬레이션을 시작할 때, 해당 지역의 최신 V3 프리미엄 데이터를 하드코딩 DB(`landmarks.ts`)로 즉시 복사해 옵니다.

- **작동 원리**: 시뮬레이션 시작 트리거 시 `export-db-to-local.ts` 로직을 API 형태로 호출.
- **이점**: 인터넷이 끊겨도(No-Wifi) 시뮬레이션 중 받은 최신 데이터는 로컬에 남아있게 됨.

## 2. Neon DB 백업 클러스터 (Backup Cluster)
데이터 유실을 방지하기 위해 `landmarks_backup` 및 `cities_backup` 테이블을 별도로 생성하고, 주기적으로 현재 상태를 미러링합니다.

- **변경 사항**: `shared/schema.ts`에 백업용 테이블 정의 추가.
- **동작**: `scripts/db-backup.ts` 생성하여 현재 DB 상태를 백업 클러스터로 덤프.
