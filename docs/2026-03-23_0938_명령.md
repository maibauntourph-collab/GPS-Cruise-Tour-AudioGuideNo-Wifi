## 🔴 발견된 문제 목록 (Issue List)

### 1. 언어 감지 범위 부족 (LanguageContext.tsx)
- `es`, `fr`, `de`, `it`, `pt`, `ru` 는 브라우저 언어 자동 감지 **미지원**
- 현재: `ko`, `th`, `ja`, `zh-*`, `vi`, `id` 만 자동 감지됨
- 결과: 유럽어 사용자도 항상 영어로 시작

### 2. 나레이션 번역 미존재 시 TTS 언어 불일치
- `getTranslatedContent()`: `landmark.translations['th']` 없으면 영어 텍스트를 반환
- 영어 텍스트를 태국어 TTS 음성으로 읽는 문제 발생
- 해결: audioService에 자동 번역 API 라우트 `/api/translate` 연동 (이미 있음)
- `playAuto()` 에서 `getTranslatedText()` 호출 확인 필요

### 3. translations.ts - `th` 언어 키 누락 다수
- `th` 언어 객체에 없는 키들: `gpsAudioGuide`, `chooseStartMethod`, `startFromGPS`, 등 40개+ 
- `t('key', 'th')` 호출 시 영어 fallback 발동 → UI 일부가 영어로 표시

### 4. StartupDialog 언어 선택기 없음
- 온보딩 화면에서 언어를 선택할 수 없어 초기 언어가 자동 감지에만 의존
- 목표: 온보딩 화면 하단에 언어 선택기 추가

### 5. playAuto() 언어 파라미터 전달 확인 필요
- GPS 나레이션 자동 재생 시 `selectedLanguage` 가 올바르게 전달되는지 검증
