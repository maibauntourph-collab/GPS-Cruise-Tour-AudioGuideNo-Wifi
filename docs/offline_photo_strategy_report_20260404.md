## 1. 개요 (Overview)
본 보고서는 **'데이터 연결 없이도 즐기는 고화질 오디오 가이드'** 실현을 위해 진행된 **오프라인 우선(Offline-First) 이미지 전략**의 결과물입니다. 기존의 불안정한 외부 이미지 링크를 고성능 캐싱 시스템과 고해상도 Unsplash 소스로 전면 교체하여 PWA 환경에서의 사용자 경험을 극대화했습니다.

---

## 2. 주요 구현 기술 (Core Technologies)

### 🧱 [Designer Kim] 오프라인 이미지 전용 컴포넌트 (`OfflineImg`)
단순한 `<img>` 태그를 넘어선 스마트 렌더링 시스템입니다.
- **온라인 모드:** 이미지를 즉시 표시하면서 백그라운드에서 `IndexedDB`에 바이너리(Blob) 형태로 저장합니다.
- **오프라인 모드:** 네트워크가 끊기면 `IndexedDB`에서 즉시 데이터를 추출하여 화면에 표시합니다.
- **애니메이션:** `framer-motion`을 이용한 부드러운 페이드인(Fade-in) 효과로 프리미엄 감성을 유지합니다.

### 🪝 [Bug Doctor] 지능형 캐싱 훅 (`useOfflineImage`)
이미지의 생명주기를 관리하는 로직의 핵심입니다.
- **상태 감지:** `online/offline` 이벤트를 실시간 모니터링하여 데이터 소스를 스위칭합니다.
- **캐시 정책:** 동일 이미지에 대해 중복 요청을 방지하고, 30일이 지난 데이터는 자동으로 갱신(Refresh)합니다.

### 🗄️ [Server Park] 고속 저장소 (`IndexedDB v4`)
- 기존 버전과의 호환성을 유지하면서 이미지 전용 저장소(Store)를 분리하여 대용량 사진 데이터(Blob)를 안전하게 관리합니다.

## 5. 검증 및 테스트 방법 (Testing Guide)

학생들이 직접 테스트해 볼 수 있는 시나리오입니다:
1.  **초기 로드:** 앱을 실행하고 관심 있는 도시(예: 로마, 파리)를 선택합니다.
2.  **캐싱 수행:** 랜드마크 목록을 스크롤하면 자동으로 백그라운드 캐싱이 진행됩니다.
3.  **오프라인 테스트:** 기기를 **비행기 모드**로 전환합니다.
4.  **결과 확인:** 다시 랜드마크 상세 페이지에 들어갔을 때, 사진이 끊김 없이 눈앞에 펼쳐지면 성공입니다!
