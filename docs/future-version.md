# 3D 네비게이션 구현 분석 결과 보고서 (Future Version)

> [!NOTE]
> 본 문서는 차기 버전 업그레이드 시 별도 프레임(웹/앱 분리 운영)으로 진행될 3D 네비게이션 기능의 기술 설계안입니다.

## 📝 개요
여행 경로 이동 시 줌인 및 3D 틸트/회전 효과를 제공하기 위한 기술 분석 결과입니다.

## ⚙️ 기술적 배경
1. **엔진 교체 필요**: 현재 `react-leaflet`(2D)에서 `MapLibre GL JS`(3D 벡터)로의 전환이 필수적임.
2. **벡터 타일 활용**: 고해상도 확대와 3D 시점 변환을 위해 벡터 타일 데이터 소스 확보 필요.

## 🏗️ 설계 아키텍처
### 1. 지도 엔진 (MapLibre GL JS)
- 벡터 타일 기반의 실시간 스타일링 및 3D 렌더링 지원.
- 하드웨어 가속을 통한 부드러운 카메라 이동.

### 2. 3D 네비게이션 로직
- **Pitch(기울기) 제어**: 시뮬레이션/이동 모드 시 60도 기울기 자동 적용.
- **Rotation(회전) 제어**: 진행 방향(Course)에 따른 지도 회전 동기화.
- **Dynamic Zoom**: 이동 속도에 따른 자동 줌 레벨 조정(16~18).

### 3. PWA 오프라인 전략
- Service Worker를 통해 벡터 타일 데이터(.pbf) 캐싱.
- 오프라인 상태에서도 지도의 기본 기능 및 3D 레이아웃 유지.
