## 🖥️ Client - 프론트엔드

### 📄 `client/src/main.tsx`
> **역할**: 앱 진입점. React 루트를 DOM에 마운트하고 QueryClient(TanStack Query)를 설정합니다.

```tsx
// 📌 학생 노트: React 앱이 시작되는 단 하나의 진입점
// QueryClientProvider는 서버 데이터 캐싱을 전역으로 관리합니다
ReactDOM.createRoot(document.getElementById('root')).render(
  <QueryClientProvider client={queryClient}>
    <App />
  </QueryClientProvider>
)
```

## 📄 Pages (페이지 컴포넌트)

### 🏠 `client/src/pages/Home.tsx` ⭐ 핵심 파일
> **역할**: 앱의 **메인 화면**. 지도, 명소 목록, 오디오 재생, 투어 관리, 다이얼로그를 모두 제어하는 최상위 컴포넌트.

| 주요 상태 | 설명 |
|-----------|------|
| `selectedLandmark` | 현재 선택된 명소 |
| `forceShowCard` | 목록 카드 강제 표시 여부 |
| `isNavigationOnlyMode` | 지도 전용 모드 (카드 숨김) |
| `isCardMinimized` | 카드 최소화 상태 |
| `isSimulationMode` | 가상 투어 시뮬레이션 여부 |
| `selectedLanguage` | 현재 선택 언어 (ko/en/ja/zh 등) |

**핵심 흐름**: 앱 시작 → InstallPrompt(웰컴) → StartupDialog(도시 선택) → 지도 표시 + 명소 목록 자동 노출

## 🔧 lib/ - 핵심 서비스 & 유틸리티

### 🔊 `audioService.ts` ⭐
> **역할**: 앱의 **오디오 재생 엔진**. MP3 직접 재생과 OpenAI TTS를 통합 관리합니다.

| 주요 기능 | 설명 |
|-----------|------|
| `play(landmark)` | 명소 오디오 재생 시작 |
| `pause()` / `resume()` | 일시정지 / 이어듣기 |
| `stopAll()` | 모든 오디오 정지 |
| TTS 좀비 방지 | Hard Reset 전략으로 TTS 엔진 안정화 |

---

### 🌐 `translations.ts` ⭐
> **역할**: 다국어 번역 시스템. 한국어(ko), 영어(en), 일어(ja), 중국어(zh), 스페인어(es), 프랑스어(fr), 독일어(de), 이탈리아어(it), 포르투갈어(pt), 러시아어(ru) 10개 언어 지원.

```ts
// 사용 예시:
getTranslatedContent(landmark, 'ko', 'name')  // 한국어 명소명
t('searchLandmarks', 'en')                    // 'Search Landmarks'
```

---

### 🔗 `affiliateConfig.ts`
> **역할**: 예약 플랫폼 URL 생성 함수 모음.

| 함수 | 이동 플랫폼 |
|------|-------------|
| `getMyRealTripUrl()` | 마이리얼트립 |
| `getTripUrl()` | Trip.com |
| `getKlookUrl()` | Klook |
| `getGYGUrl()` | GetYourGuide |
| `getViatorUrl()` | Viator |
| `getWikiUrl()` | Wikipedia |
| `getGoogleSearchUrl()` | Google 검색 |

---

### 💾 `offlineStorage.ts`
> **역할**: IndexedDB 기반 **오프라인 데이터 저장소**. WiFi 없는 환경에서 명소 정보와 오디오를 로컬 캐시에서 불러옵니다.

---

### 📍 `locationService.ts`
> **역할**: GPS 위치 추적 서비스. Geolocation API를 래핑하여 실시간 위치 업데이트와 오류 처리를 제공합니다.

---

### 🗺️ `geoUtils.ts`
> **역할**: 위도/경도 거리 계산 유틸리티 (Haversine 공식).

---

### 🔒 `offlineDataEncryption.ts`
> **역할**: 오프라인 저장 데이터 암호화/복호화 (AES). 저작권 보호와 보안을 위해 MP3 오디오를 암호화합니다.

---

### ⚙️ `voiceSettings.ts`
> **역할**: TTS 음성 설정 (속도, 음역, 언어별 목소리) 관리.

---

### 🔄 `syncService.ts`
> **역할**: 온라인 복귀 시 서버와 로컬 데이터 동기화.

## 🖧 server/ - 백엔드

### 📡 `server/index.ts`
> **역할**: 서버 **진입점**. Express 앱을 초기화하고 포트(5000)에서 리스닝합니다.

---

### 📡 `server/app.ts`
> **역할**: Express 미들웨어 설정. CORS, JSON 파싱, 세션, 정적 파일 서빙을 설정합니다.

---

### 🗄️ `server/routes.ts` / `server/routes_express.ts`
> **역할**: **API 라우터**. 명소, 도시, 오디오, 유저, 배지, 투어 관련 REST API 엔드포인트 정의.

| 주요 API | 설명 |
|----------|------|
| `GET /api/landmarks` | 명소 목록 조회 |

| `POST /api/audio/tts` | OpenAI TTS 음성 생성 |
| `GET /api/user/badges` | 사용자 배지 조회 |
| `POST /api/tours` | 투어 저장 |

### 🗄️ `server/storage.ts`
> **역할**: **데이터 접근 레이어(DAL)**. NeonDB (PostgreSQL)와 Drizzle ORM을 사용해 CRUD를 처리합니다.

---

### 🔐 `server/auth.ts`
> **역할**: 인증 미들웨어. Passport.js + Google/Kakao OAuth 전략을 사용합니다.

---

### 🔐 `server/oauth-providers.ts`
> **역할**: Google, Kakao 소셜 로그인 Provider 설정.

---

### 🗄️ `server/db.ts`
> **역할**: NeonDB 커넥션 풀 생성 및 Drizzle ORM 인스턴스 초기화.

### ☁️ `server/worker.ts`
