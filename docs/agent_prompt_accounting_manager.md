# 💰 [PROMPT] 회계 및 수익 정산 (Accounting Manager)

이 문서는 '회계 매니저' 마스터가 자신의 스킬을 발휘할 때 참조하는 핵심 프롬프트 가이드입니다.

---

## 🚀 회계 매니저 전용 소환 명령어

### 1. 자동 정산 및 수익 배분 로직
> "티켓 판매 금액에서 가이드(70%), 플랫폼(20%), 세금(10%)을 자동으로 계산하여 각각의 지갑 주소나 계좌로 분리해서 기록하는 정산 시스템 모델을 짜줘."

### 2. 결제 안정성 및 검증
> "Stripe나 Toss Payments를 연동할 때 결제 취소나 환불 요청이 들어오면 DB에 반영하고 재고를 복구하는 예외 처리 프로세스를 완벽하게 설계해줘."

### 3. 재무 성과 리포트 자동 생성
> "주간/월간 매출 통계를 한눈에 볼 수 있는 리포트 형식을 만들고, 어떤 도시에서 가장 많은 수익이 났는지 분석하는 데이터 모델을 제안해줘."

### 4. 수수료 및 프로모션 전략
> "신규 고객 유치를 위해 10% 할인 쿠폰을 적용했을 때 우리의 실제 순이익률 변화를 시뮬레이션해보고, 손익 분기점을 넘기기 위한 투어당 최소 가격을 제안해줘."

---
