# [기획/설계] Landing Page 내 Shopify 프리미엄 쇼핑 홍보 및 진입점 강화

교수님의 지침에 따라, 사용자가 앱에 진입하는 첫 관문인 **Landing Page (RoleSelection.tsx)**에 새로운 쇼핑 경험을 미리 엿볼 수 있는 프리미엄 티저 요소를 추가합니다.

## 1. 목적
사용자가 맵에 들어가기 전부터 "이 앱으로 로컬 명품 쇼핑이 가능하다"는 가치를 전달하여 앱의 프리미엄 이미지를 강화하고 사용성을 높입니다.

## 2. 주요 변경 사항

### [RoleSelection.tsx] - 랜딩 페이지 고도화
- **Traveler Mode 카드 강화**: '관광객 모드' 카드 하단에 쇼핑 아이콘과 함께 "프리미엄 로컬 선물 쇼핑 가능"과 같은 짧은 강조 문구 추가.
- **피처 하이라이트 배지**: 쇼핑 기능이 새로 추가되었음을 알리는 'NEW: Premium Shopping' 플로팅 배지 또는 텍스트 애니메이션 추가.

### [translations.ts] - 티저용 문구 추가
- 랜딩 페이지에서 사용할 매력적인 쇼핑 홍보 문구(ko/en) 추가.
  - 예: "장인이 만든 명소 기념품을 오프라인에서도 만나보세요" / "Discover handcrafted local gifts, even offline."

## 3. 비주얼 컨셉 (Designer Kim 제안)
- **아이콘**: `lucide-react`의 `ShoppingBag` 또는 `Gift` 아이콘 사용.
- **색상**: 기존 테마의 포인트 컬러인 `#E67E22`(오렌지)와 조화로운 골드/앰버 계열의 그라데이션 사용.
- **애니메이션**: 사용자가 카드를 호버하거나 화면에 진입할 때 쇼핑 관련 텍스트가 살짝 반짝이는 효과.

## 4. 검증 계획

### 수동 확인 (Manual Verification)
1. **랜딩 페이지 진입**: `npm run dev` 실행 후 첫 화면에서 'Traveler Mode' 카드에 쇼핑 홍보 문구가 잘 보이는지 확인.
2. **다국어 확인**: 한국어/영어 전환 시 쇼핑 홍보 문구가 적절하게 번역되어 노출되는지 확인.
3. **디자인 조화**: 기존 Glassmorphism 디자인과 이질감 없이 프리미엄하게 연출되었는지 Designer Kim의 시각으로 검토.
