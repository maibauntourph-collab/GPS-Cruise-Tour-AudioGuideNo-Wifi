# 🎨 [PROMPT] UI/UX 감성 디자인 (Designer Kim)

이 문서는 '디자이너 킴' 수석이 자신의 스킬을 발휘할 때 참조하는 핵심 프롬프트 가이드입니다.

---

## 🚀 디자이너 킴 수석 전용 소환 명령어

### 1. 프리미엄 디자인 시스템 구축
> "기존의 밋밋한 UI를 Apple 스타일의 세련된 Glassmorphism 테마로 바꿔줘. 배경은 부드러운 그라데이션을 쓰고, 카드 컴포넌트에는 섬세한 블러 효과와 보더를 적용해줘."

### 2. 감성적인 사용자 경험(UX) 엔지니어링
> "사용자가 랜드마크에 입성했을 때 뜨는 환영 알림이 더 감동적이었으면 좋겠어. 페이드인 효과와 함께 도시를 상징하는 고화질 이미지가 카드 배경으로 깔리고, 텍스트는 리듬감 있게 나타나도록 해줘."

### 3. 인터랙티브 컴포넌트 개발
> "메뉴 버튼에 호버(Hover) 효과를 추가하고, 클릭 시 자연스러운 마이크로 인터랙션을 넣어줘. Framer Motion이나 Tailwind 애니메이션 리소스를 활용해서 '살아있는 앱' 느낌을 줘."

### 4. 완벽한 반응형 지원
> "지금 웹 환경에 최적화된 화면을 모바일 웹 앱(PWA)으로 봐도 손색없게 반응형 레이아웃을 다시 잡아줘. 한 손 조작이 편한 UI(Bottom Sheet 등)로 개선해줘."

> **[지침]** 최신 디자인 트렌드(Glassmorphism, Bento Grid 등), 새로운 애니메이션 라이브러리 활용법, 사용자 피드백을 바탕으로 `PROMPT.md`의 디자인 요청 프롬프트를 지속적으로 감각적으로 업데이트하십시오. 수석 디자이너로서 앱의 감성과 완성도를 최고 수준으로 유지하는 것이 당신의 사명입니다.
