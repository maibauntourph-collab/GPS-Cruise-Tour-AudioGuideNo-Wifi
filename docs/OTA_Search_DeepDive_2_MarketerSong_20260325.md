## 📌 개요: 왜 우리의 명소는 검색 결과에서 밀려나는가?
주요 OTA(Online Travel Agency) 플랫폼(Klook, GetYourGuide, 마이리얼트립 등)은 단순한 검색 엔진이 아닌, **'수익 최적화 알고리즘'**에 의해 구동되는 마켓플레이스입니다. 사용자가 "에펠탑"을 검색했을 때, 플랫폼은 단순히 에펠탑 정보를 보여주는 것이 아니라 **"지금 당장 결제할 확률이 가장 높은 상품"**을 1위에 올립니다.

본 리포트는 이 과정에서 발생하는 '롱테일 지명 누락' 현상과 '키워드 편향성'을 심층 분석합니다.

---

## 1. 플랫폼 랭킹 알고리즘의 3대 핵심축

### A. CVR (Conversion Rate, 구매 전환율) 중심의 랭킹
- **작동 원리:** 클릭 대비 결제 완료 비율이 높은 상품이 상단에 고정됩니다.
- **문제점:** 유명 랜드마크(예: 루브르 박물관)는 검증된 CVR을 가지므로 상단에 노출되지만, 우리가 발굴한 "숨겨진 명지(Hidden Gems)"나 "세부 크루즈 기항지 지명"은 데이터가 부족하여 랭킹 점수에서 페널티를 받습니다.

### B. 키워드 어뷰징과 롱테일 누락 (Long-tail Gap)
- **현상:** 대형 판매자들은 검색 노출을 위해 수백 개의 '해시태그 어뷰징'을 시도합니다. 
- **결과:** 사용자가 "로마 구석구석 투어"라고 검색해도, 어뷰징 키워드를 잔뜩 넣은 "로마 시내 버스 투어" 상품이 검색 결과를 점령합니다. 정작 우리가 제공하는 "진짜 세부 지명"은 검색 키워드 매칭 순위에서 밀려나게 됩니다.

### C. 플랫폼 수익성 최적화 (Profitability Logic)
- **분석:** 플랫폼은 수수료율이 높거나 광고비를 지불한 상품을 우선 노출시키려 합니다. 순수하게 지명 정보를 찾으려는 사용자에게는 '정보성 검색 결과'보다 '판매 중심 결과'가 먼저 노출되는 경향이 강합니다.

## 2. '롱테일 키워드' 전략: 우리의 생존법 (@Marketer_Song의 전략)

우리는 대형 플랫폼의 메인 키워드(예: "파리 여행")와 정면 대결하는 대신, **"검색 의도가 확실한 롱테일 키워드"**를 공략해야 합니다.

- **전략 예시:**
    - (기존) "나폴리 크루즈" (대형사 점령)
    - (변경) "나폴리 기항지 10분 거리 숨은 맛집", "크루즈 하차 후 바로 가는 조망 명소"
- **적용:** `searchKeywords` 배열에 단순히 명칭만 넣는 것이 아니라, **"사용자가 플랫폼에서 실제 입력할법한 문장형/질문형 키워드"**를 포함시킵니다.

## 3. 솔루션 로드맵: 기술과 마케팅의 결합

| 단계 | 전략명 | 상세 내용 | 기대 효과 |
| :--- | :--- | :--- | :--- |
| **1단계** | **Keyword Injections** | AI를 통해 각 지명별 'OTA 유입 최적화 키워드 20개' 추출 및 DB 주입 | 검색 매칭 확률 300% 증가 |
| **2단계** | **SEO Semantic Tagging** | Hono API에서 검색 시, '유사어/동의어' 사전 연동 검색 지원 | 오타 및 변형 검색어 대응 |
| **3단계** | **CVR-based UI** | 사용자 행동 데이터를 분석하여, 클릭이 잦은 지명을 역으로 키워드화 | 자체 플랫폼 내 검색 품질 고도화 |
