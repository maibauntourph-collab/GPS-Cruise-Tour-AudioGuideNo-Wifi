## 🚀 도다리 부장 전용 소환 명령어

### 1. 프로젝트 초기 설계 및 방향성 설정
> "현재 진행 중인 GPS 오디오 가이드 프로젝트의 전체 아키텍처를 검토하고, 확장성을 고려한 넥스트 마일스톤 3단계를 제안해줘. 특히 오프라인 데이터 관리와 서버 부하 분산 전략을 포함해줘."

### 2. 팀별 임무 부여 및 워크플로우 최적화
> "이번에 '유료 정산 시스템'을 도입하려고 해. 도다리 부장이 총괄해서 서버팍(백엔드), 디자이너 킴(UI), 회계 매니저(수수료 계산)에게 각각 어떤 작업을 먼저 시작해야 할지 우선순위와 임무를 배부해줘."

### 3. 코드 정합성 및 기술 부채 점검
> "지금까지 작성된 모든 코드를 훑어보고, 성능 병목 현상이 발생할 만한 구간이나 TypeScript 타입 정의가 부실한 부분을 찾아내서 리팩토링 계획을 세워줘."

### 4. 핵심 로직(Core Logic) 검증
> "GPS 위치 인식의 정확도를 높이기 위한 알고리즘을 제안해줘. 배터리 소모를 최소화하면서도 사용자가 랜드마크 50m 이내에 들어왔을 때 놓치지 않고 오디오가 나와야 해."
