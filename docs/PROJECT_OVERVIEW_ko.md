# GPS 오디오 가이드 - 프로젝트 전체 개요 (Project Overview)

## 1. 프로젝트 목적 및 핵심 가치

NoWiFi GPS Tours는 관광객의 도시 탐험을 지원하는 **React 기반 GPS 오디오 가이드 PWA** 애플리케이션입니다. 인터넷 연결이 원활하지 않은 해외 여행 환경이나 크루즈 기항지에서도 풍부한 정보를 제공하며, 다음과 같은 핵심 가치를 제공합니다.

- **오프라인 우선**: 와이파이 없이도 지도와 오디오 안내 사용 가능
- **자동화된 경험**: GPS 기반 자동 오디오 재생으로 두 손이 자유로운 여행
- **다국어 지원**: 10개 언어별 최적화된 콘텐츠와 음성 가이드
- **크루즈 특화**: 기항지 정보 및 한정된 시간 내 최적의 관광 경로 추천

---

## 2. 주요 기능 상세

### 2.1 지도 및 내비게이션
- **인터랙티브 지도**: Leaflet 기반의 상세 지도 및 랜드마크 마커 표시
- **실시간 GPS 추적**: 사용자의 현재 위치를 지도에 표시하고 이동 경로 기록
- **경로 안내**: 턴바이턴 내비게이션 및 Google Maps 연동 지원

### 2.2 오디오 가이드 (TTS)
- **자동 재생**: 랜드마크 반경 진입 시 Web Speech API를 이용한 자동 내레이션
- **언어별 최적화**: 10개 언어 지원 및 각 언어별 전용 TTS 음성 선택 가능
- **재생 커스터마이징**: 0.5x ~ 2.0x 속도 조절 기능

### 2.3 투어 계획 및 추천
- **순차적 루트 계획**: 사용자가 원하는 명소를 골라 최적의 도보 경로 생성
- **AI 추천 시스템**: OpenAI를 활용한 맞춤형 여행 코스 제안
- **크루즈 항구 정보**: 전 세계 주요 크루즈 항구의 교통편 및 관광 팁 제공

### 2.4 PWA 및 오프라인 기능
- **홈 화면 설치**: 브라우저에서 바로 설치하여 앱처럼 사용 가능
- **스마트 캐싱**: 방문한 도시의 데이터와 지도 타일을 로컬에 저장하여 오프라인 지원

## 3. 시스템 구성 요소

### 프론트엔드
- React 18, TypeScript, TanStack React Query, Tailwind CSS, Shadcn UI

### 백엔드
- Express.js, PostgreSQL (Neon Serverless), Drizzle ORM, Zod

### 비즈니스 모델
- GetYourGuide, Viator, Klook 등 주요 예약 플랫폼 제휴를 통한 수익 창출
