# 오프라인 TTS 캐싱 기능 구현 완료 보고서

## 개요
오프라인 모드에서도 끊김 없는 오디오 가이드 제공을 위해, OpenAI TTS에 이어 CLOVA TTS에 대한 오프라인 캐싱 로직을 `audioService.ts`에 성공적으로 구현하였습니다.

## 작업 내용

### 1. CLOVA TTS 문장 재생 로직 (`playNextClovaSentence`) 개선
- **기존 문제점**: 문장 단위 재생 시 매번 API를 호출하여 네트워크 트래픽 발생 및 오프라인 시 재생 불가.
- **개선 사항**:
    - **캐시 우선 전략**: 재생 전 `offlineStorage`에서 캐시된 오디오 파일 확인.
    - **자동 저장**: API를 통해 생성된 오디오를 `audioFiles` 스토어에 자동 저장.
    - **고유 키 생성**: `clova-{voiceId}-{sentence}` 형식의 키를 사용하여 목소리 변경 시에도 충돌 방지.
    - **재생 최적화**: `playAudioBlob` 메서드를 재사용하여 코드 중복 제거 및 일관성 확보.

### 2. IndexedDB 스키마 확인
- `offlineStorage.ts`의 `audioFiles` 스토어를 활용하여 오디오 데이터(Blob), 지속 시간, 크기 등의 메타데이터를 효율적으로 관리.

## 기대 효과
- **데이터 절약**: 한 번 재생된 문장은 다시 다운로드하지 않음.
- **오프라인 지원**: 미리 캐싱된 오디오는 인터넷 연결 없이도 재생 가능.
- **반응 속도 향상**: 로컬 캐시 사용 시 네트워크 지연 없이 즉시 재생.

## 향후 계획
- 오프라인 패키지 다운로드 시 전체 TTS 오디오를 일괄 생성 및 캐싱하는 기능 고려.
- 캐시 용량 관리 정책 (LRU 등) 수립 필요 시 검토.
