## 5. PhotoManager.tsx — 사진 관리

**BMAD 에이전트:** `designer_kim`
**LangGraph:** Graph #1

```

**UI 플로우:**
1. 왼쪽: 도시 목록 테이블 (장소명 / 사진수 / 상태 / 편집 버튼)

3. 저장 시 토스트: "✅ 사진이 저장되었습니다!"

**상태 색상:**
- 완료: `text-emerald-400`
- 진행중: `text-amber-400`

```

```

**카테고리 탭:**
```
전체 | 🗿 랜드마크 | 🍽️ 레스토랑 | 🎯 액티비티 | 🎁 기념품점 | 🤖 AI 추천
```

**[전체/카테고리 탭] 관광지 테이블:**
- 컬럼: 국가/도시 / 장소명 / 카테고리 뱃지 / GPS 좌표 / 추천수 / 액션(편집/사진/추천)
- 상단 우측: "+ 새 장소 추가" + "🤖 AI 일괄 추천 생성"

**[🤖 AI 추천 탭] 추천 테이블:**
- 필터 버튼: 전체 / ⏳ 대기 / ✅ 승인 / ❌ 거절
- 컬럼: 기준 장소 / 추천 장소 / 카테고리 / 거리 / AI 출처 / 상태 뱃지 / 액션
- 대기 상태만 승인/거절 버튼 활성화

**상태 뱃지:**
```
pending  → amber-400  bg-amber-950/20  border-amber-900/40
approved → emerald-400 bg-emerald-950/20 border-emerald-900/40
rejected → red-400    bg-red-950/20    border-red-900/40

## 8. AIKeyManager.tsx — AI API KEY & 토큰 관리

**BMAD 에이전트:** `automation_doctor`
**LangGraph:** Graph #4 (키 로테이션)

**API 연결:**
```
GET   /api/admin/ai-accounts         → AI 계정 전체 목록
POST  /api/admin/ai-accounts         → 새 계정 추가
PATCH /api/admin/ai-accounts/:id     → 상태 변경 (active/standby)
```

**상단 카드 그리드 (4개):**
- 🟣 Claude: 3개 계정 / 41% 사용
- 🔵 Gemini: 2개 계정 / 89% ⚠️
- 🟢 ChatGPT: 2개 계정 / 26% 사용
- ➕ 새 AI 추가

**AI 계정 카드 항목:**
- 이메일(메모) / 모델명 / 메모
- 토큰 사용량 프로그레스 바 (80% 초과 시 amber-400 경보)
- 상태 뱃지: ✅ 활성 / ⏸️ 대기
- 버튼: 테스트 / 수정 / 활성화 또는 비활성화

**전환 방식 (radio):**
- `manual` — 수동
- `auto` — 자동 (한도 초과 시)
- `round_robin` — 라운드 로빈

**새 계정 추가 모달 (Dialog):**
- 이메일(메모용) / API Key / 월 한도(토큰) / 메모 / 모델 선택
- 버튼: 취소 / 연결 테스트 / 저장

**하단 월간 토큰 요약 테이블:**
- 컬럼: AI 엔진 / 계정수 / 이달 사용 / 이달 한도 / 사용률 바

## 11. DB 스키마 (shared/schema.ts)

### `ai_accounts` 테이블
```sql
id           serial PRIMARY KEY
engine_name  varchar(50)   -- claude / gemini / chatgpt / custom
display_name varchar(100)
email_memo   varchar(255)
api_key      text          -- AES-256 암호화
model_name   varchar(100)
status       varchar(20)   -- active / standby / disabled
switch_mode  varchar(20)   -- manual / auto / round_robin
sort_order   integer
usage_count  integer DEFAULT 0
usage_limit  integer DEFAULT 30000
last_used_at timestamp
```

### `recommend_places` 테이블
```sql
id           serial PRIMARY KEY
source_id    integer       -- landmarks.id 또는 cities.id
source_type  varchar(20)   -- 'city' | 'landmark'
place_name   varchar(255)
place_name_ko varchar(255)
ai_account_id integer REFERENCES ai_accounts(id)
status       varchar(20) DEFAULT 'pending'  -- pending / approved / rejected
created_at   timestamp DEFAULT now()
approved_at  timestamp
```

### `landmark_audio` 테이블
```sql
id           varchar PRIMARY KEY DEFAULT gen_random_uuid()
landmark_id  varchar NOT NULL
language     varchar(10)   -- 'en', 'ko', 'ja', 'zh'
audio_url    varchar        -- MP3 경로
duration     integer        -- 초 단위
```
