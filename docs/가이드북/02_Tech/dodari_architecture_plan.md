# [도다리] 지능형 UI 시퀀스 아키텍처 고도화 설계

사용자님의 지시에 따라, **도다리 부장**이 첫 번째 순서로 서비스의 지능형 흐름 제어권을 강화합니다.

## 🎖️ 설계 목표
단순히 "창이 닫히면 뜬다"는 로직을 넘어, **사용자가 무엇을 바꿨는가**에 따라 환영 페이지의 노출 여부를 지능적으로 결정합니다.

## 🛠️ 핵심 변경 사항

### 1. 설정 의도 추적 (Intent Tracking)
- 사용자가 설정창(`SettingsDialog`)을 열고 닫을 때, 단순 구경이었는지 아니면 실제 '도시'를 변경했는지를 구분하는 상태값(`lastSettingsAction`)을 도입합니다.

### 2. 조건부 랜딩 트리거 (Conditional Trigger)
- **도시 변경 시**: 즉시 해당 도시의 `Magic Landing`을 트리거하여 환영 인사를 건넵니다.
- **단순 설정(음성 등) 변경 시**: 이미 랜딩을 봤다면 불필요한 재노출을 억제하여 사용자의 흐름을 방해하지 않습니다.
- **초기 진입 시**: 모든 설정을 완료한 직후 최고의 감동을 선사합니다.

### 3. 상태 머신(State Machine) 고도화
- `Home.tsx` 내의 UI 시퀀스를 관리하는 독립적인 훅(`useUISequence`)으로 로직을 분리하기 위한 초석을 다집니다.

## 🩺 디버그 닥터 협력 포인트
- 각 상태 변화 시점에 `[Dodari Architecture] Intent Identified: CITY_CHANGE`와 같은 정교한 로그를 남겨 디버깅을 용이하게 합니다.
