# Antigravity 사용 가이드

Antigravity는 이 프로젝트의 개발을 돕는 AI 코딩 어시스턴트입니다. 다음과 같은 작업들을 요청할 수 있습니다.

## 1. 새로운 기능 추가
새로운 기능이 필요할 때 요청하세요.
- **예시**: "새로운 도시인 '도쿄'를 데이터베이스에 추가하고 관련 랜드마크 5개를 등록해줘."
- **결과**: Antigravity가 스키마를 확인하고, 필요한 데이터를 `server/storage.ts`에 추가하며, UI에 반영되도록 코드를 수정합니다.

## 2. 버그 수정 및 디버깅
프로그램 작동 중 오류가 발생하면 에러 메시지와 함께 요청하세요.
- **예시**: "지도를 클릭할 때 팝업이 뜨지 않아. 콘솔 로그를 확인하고 수정해줘."
- **결과**: Antigravity가 브라우저 도구를 사용하여 에러를 재현하고, 원인을 분석한 후 수정한 뒤 검증까지 완료합니다.

## 3. UI 및 디자인 개선
디자인이 마음에 들지 않거나 개선이 필요할 때 요청하세요.
- **예시**: "메인 페이지의 테라코타 색상을 조금 더 부드러운 오렌지 톤으로 바꿔줘."
- **결과**: Tailwind CSS 설정을 변경하고, UI 컴포넌트의 스타일을 일괄적으로 업데이트합니다.

## 4. 문서화 및 코드 설명
코드가 복잡해서 이해가 가지 않을 때 질문하세요.
- **예시**: "현재 다국어 번역 시스템이 어떻게 작동하는지 설명해주고, 새로운 언어를 추가하는 절차를 문서로 만들어줘."
- **결과**: 관련 코드(`client/src/lib/translations.ts`)를 분석하여 상세한 설명과 가이드를 제공합니다.

---

### Antigravity와 대화하는 팁
- **구체적으로 요청하기**: 원하는 바를 명확히 설명할수록 정확한 결과가 나옵니다.
- **단계별 진행**: 큰 작업은 "우선 계획부터 세워줘"라고 말하며 단계를 나누어 진행할 수 있습니다.
- **승인 프로세스**: Antigravity가 제안하는 `implementation_plan.md`를 확인하고 승인하면 작업을 시작합니다.
