## 🏛️ [Part 1] 프로젝트의 시초와 기술적 도전

### 1.1 오프라인은 타협할 수 없는 가치입니다
크루즈 여행객이 기항지에 내렸을 때 가장 큰 고통은 '데이터 사막'입니다. 우리는 인터넷 없이도 GPS 위치를 추적하고, 주변 명소를 한국어로 설명해 주는 **'진짜 오프라인'** 앱을 목표로 했습니다.

### 1.2 선택된 기술 스택 (The Modern Stack)
| 계층 | 기술 | 선택 이유 |
|:---:|:---|:---|
| **Frontend** | React 18 + Vite | PWA(Progressive Web App) 구현의 최적체 |
| **Backend** | Hono (Cloudflare Workers) | 초경량, 초고속 엣지 컴퓨팅 |
| **Database** | Neon DB (PostgreSQL) | 서버리스 환경에 최적화된 DB |
| **Styling** | Tailwind CSS + Shadcn UI | 일관성 있고 프리미엄한 디자인 시스템 |
| **Data Flow** | TanStack Query v5 | 강력한 캐싱과 오프라인 데이터 관리 |

## 🤖 [Part 2] 8인의 AI 전문가 팀 (The Agents)

우리는 단순히 AI에게 코딩을 시키지 않았습니다. **BMAD(Business-Marketer-Architect-Developer)** 프레임워크를 기반으로 8명의 전문 페르소나를 설정하여 군단(Legion)처럼 움직였습니다.

### 2.1 에이전트 조직도
1. **🎖️ 도다리 (Chief Architect)**: 전체 설계를 책임지며 아키텍처와 마일스톤을 관리합니다.
2. **⚙️ 서버팍 (Backend Master)**: Cloudflare Workers, API 최적화, 보안의 전문가입니다.
3. **🎨 디자이너 킴 (Creative Director)**: 앱의 감성과 프리미엄한 UI/UX를 담당합니다.
4. **🗳️ 쿼리 마스터 (DB Expert)**: 복잡한 SQL과 데이터 무결성을 담당합니다.
5. **🩺 오토메이션 닥터 (Automation)**: 크론 작업과 자동 업데이트 파이프라인을 구축합니다.
6. **📢 마케터 송 (Growth Hacker)**: SEO, SNS 배포 전략, 어필리에이트 수익 모델을 설계합니다.
7. **💰 회계 매니저 (FinOps)**: 수수료 계산과 매출 시뮬레이션을 담당합니다.
8. **📝 스토리텔러 이 (Content Creator)**: 사용자에게 감동을 주는 몰입형 해설을 작성합니다.

> **에이전트 활용 팁**: "디자이너 킴, 이 화면에 글래스모피즘 효과를 적용해서 프리미엄한 느낌을 살려줘"라고 전문성을 호출할 때 최고 수준의 답변이 나옵니다.

## 🔄 [Part 3] BMAD 워크플로우: 14단계의 질서

AI와 2개월간 혼돈 없이 개발할 수 있었던 비결은 14단계로 정의된 **BMAD 워크플로우** 덕분입니다. 100개가 넘는 `step-*.md` 파일들은 에이전트들이 길을 잃지 않는 등대가 되었습니다.

1. **상황 인식 (Context Loading)**: `step-01` 코딩 시작 전 과거의 맥락과 규칙을 불러옵니다.
2. **문제 정의 (Planning)**: 기술 사양서와 비교하여 현재 구현할 목표를 명확히 합니다.
3. **구현 (Execution)**: 서버팍과 디자이너 킴이 주도하여 실제 코드를 작성합니다.
4. **검증 및 에러 처리 (Verification/Error)**: `step-v-*`, `step-e-*` 오류 발생 시 디버그 닥터가 개입합니다.

## 🔥 [Part 4] 실전 트러블슈팅: 화이트스크린과 TTS

### 사건 1: 02-22 죽음의 화이트스크린
초기 PWA 도입 시 오프라인 캐싱 로직의 충돌로 사용자 화면이 하얗게 변하는 현상이 발생했습니다.
- **해결**: `workbox`를 도입하고 캐시 우선순위(Network First vs Cache First)를 API 성격에 맞게 분리. 

### 사건 2: 03-22 TTS 파이프라인의 언어 매핑 치명타
일본어와 중국어 번역 데이터가 TTS 시스템과 연결될 때 성별(gender) 변수 누락으로 에러가 떨어졌습니다.
- **해결**: 오디오 메타데이터 구조를 재설계. `server/lib/clova.ts`에서 언어 코드별 예외 처리를 정규화했습니다.

## 💼 [Part 5] 비즈니스 코드와 수익화 모델

오픈소스 프로젝트가 아닌 수익을 내는 B2C 모델로서, AI 에이전트는 코드뿐 아니라 비즈니스 로직도 짰습니다.

1. **어필리에이트 파이프라인**: GetYourGuide(8%), Viator(8%) 수익 공유를 위해 링크 제너레이터를 자동화
2. **프리미엄 전환 필터**: `isPremium=true`일 경우 오디오 50초 이후 플레이 제한 로직 구현
3. **SEO 렌더링**: 구글 봇이 JavaScript 없이도 랜드마크 텍스트를 인덱싱할 수 있도록 SSR 부분 적용

## 🚀 [Part 6] AI와 함께 걷는 개발자의 미래 (Lessons Learned)

538개의 문서, 100개가 넘는 작업 명령. AI와 협업하는 개발자는 더 이상 코더가 아니었습니다.

1. **개발자는 '감독(Director)'이 되어야 한다**: 코드는 AI가 짭니다. 개발자는 아키텍처를 그리고, 페르소나들을 조율하며 최종 컨펌을 내리는 역할을 해야 합니다.
2. **문서화는 대화의 필수 조건이다**: AI의 컨텍스트는 증발하기 쉽습니다. 우리는 `total_progress.md` 하나로 수개월의 맥락을 연결할 수 있었습니다.
3. **선택과 집중**: 인프라 세팅(Cloudflare)과 DB(Neon) 같은 복잡한 설정은 철저하게 서버팍(에이전트)에게 맡기고, 저는 사용자 경험(UX) 결정에 에너지를 집중했습니다.
