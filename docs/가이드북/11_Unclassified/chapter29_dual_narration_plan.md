# [Chapter 29] 나레이션 옵션 이원화 및 데이터 일원화 계획서

> 📅 **기록일:** 2026년 3월 25일 (수) 01:10
> 👨‍🏫 **담당 에이전트:** Designer Kim (UI), Server Park (구조), Bug Doctor (싱크)

### 🎯 핵심 목표
`detailedDescription`을 유일한 진실의 원천(Source of Truth)으로 삼아, 사용자가 원하는 깊이의 정보를 선택할 수 있도록 두 화면의 UI와 로직을 동기화합니다.

---

### 🛠️ 구현 제안 (Proposed Changes)

#### 1. [UI] 텍스트 이원화 옵션 버튼 추가
화면 상단(다이얼로그 및 플로팅 카드 공통)에 두 가지 모드 전환 버튼을 배치합니다.

- **Option A: [요약 가이드 - Guide]**
  - 바쁜 여행자를 위해 `description` 필드(짧은 요약)를 나레이션하고 텍스트 하이라이팅을 제공합니다.
- **Option B: [상세 역사 - Full Insight]**
  - 깊이 있는 정보를 원하는 여행자를 위해 `detailedDescription` 필드를 전체 나레이션하고 텍스트 하이라이팅을 제공합니다.

#### 2. [Logic] 데이터 싱크 일원화
두 컴포넌트(`LandmarkDetailDialog`, `UnifiedFloatingCard`)가 동일한 `audioContentType` 상태를 공유하도록 조정하거나, 적어도 동일한 선택 규칙을 따르도록 코드를 수정합니다.

- **표준 규칙**: 
  - 기본값은 **[상세 역사]** 모드 (`detailedDescription`).
  - 사용자가 전환 시 모든 화면에서 동시에 텍스트가 바뀝니다.

#### 3. [UX] 시각적 동기화
좌측 큰 화면에서 재생 중일 때 우측 플로팅 카드에서도 동일한 문장이 하이라이팅되도록(`currentSentenceIndex` 공유 고려) 보완합니다.

---

### ✅ 검증 계획
1. **싱크 확인**: 좌측 다이얼로그에서 문서를 읽을 때 우측 카드에서도 동일한 문장에 하이라이트가 들어오는지 확인.
2. **옵션 전환**: '요약/상세' 버튼 클릭 시 텍스트 본문과 읽어주는 음성이 즉시 교체되는지 확인.
3. **PWA 테스트**: 오프라인 환경에서도 이 두 옵션이 정상적으로 번역되어 나오는지 확인.
