# 랜드마크 데이터 정리 보고서

작성일: 2026-04-04

---

## 1. 작업 배경

앱 화면에 "파리 프리미엄 Landmark 추천 53", "런던 프리미엄 Landmark 추천 41" 등
의미 없는 더미(dummy) 데이터가 실제 랜드마크로 표시되는 문제 발견.

더미 데이터는 **DB(Neon PostgreSQL)** 와 **`server/data/landmarks.ts` 파일** 양쪽에 존재.

## 4. 삭제 패턴 분류

```
더미 랜드마크 이름 패턴:
  - "도시명 프리미엄 Landmark 추천 N"
  - "도시명 프리미엄 Restaurant 추천 N"
  - "도시명 프리미엄 Activity 추천 N"
  - "도시명 프리미엄 Shopping 추천 N"
  - "SEOUL Premium Activity N"
  - "SEOUL Premium Landmark N"
  - "TOKYO Premium Restaurant N"
  - "TOKYO Premium Shopping N"
```

공통 특징:
- 나레이션이 모두 동일한 템플릿 텍스트 반복
- 실제 위치 좌표(lat/lng)가 없거나 부정확
- 사진 없음
