# 📱 NoWiFi GPS Tours 사용자 매뉴얼 (User Manual)
> **인터넷 없이도 중단 없는 여행의 즐거움!** 본 가이드는 여행객 여러분이 앱을 200% 활용하는 방법을 안내합니다.

---

## 🚀 1. 앱 설치 및 시작 (PWA)
NoWiFi GPS Tours는 별도의 앱스토어 방문 없이 설치 가능한 최신 **PWA(Progressive Web App)** 기술을 사용합니다.

- **iPhone (iOS)**: Safari 브라우저 하단의 **'공유'** 아이콘 클릭 ➡️ **'홈 화면에 추가'** 선택.
- **Android**: Chrome 브라우저 우측 상단 **'점 3개'** 클릭 ➡️ **'앱 설치'** 또는 **'홈 화면에 추가'** 선택.
- **효과**: 홈 화면에 아이콘이 생기며, 인터넷이 불안정한 기항지에서도 앱처럼 빠르게 실행됩니다.

---

## 🌐 2. 언어 및 설정 (12개 국어 지원)
전 세계 어디서든 모국어로 안내를 받으세요.
- **언어 변경**: 화면 상단의 **'언어(Language)'** 또는 **'지구본'** 아이콘을 클릭하여 선택하세요. (한국어, 태국어, 영어, 일본어, 중국어 등 12개 국어 지원)
- **태국어 지원**: 최근 업데이트를 통해 태국 명소와 UI가 완벽하게 번역되었습니다 (ไทย).

---

## 🗺️ 3. 명소 탐색 및 오디오 투어
- **지도 탐색**: 내 주변의 명소가 지도 위에 마커로 표시됩니다. 마커를 클릭하여 상세 정보를 확인하세요.
- **리스트 보기**: 하단 탭의 **'리스트(List)'**를 선택하면 거리순으로 정렬된 명소를 한눈에 볼 수 있습니다.
- **오디오 재생**: 명소 상세 페이지에서 **'재생(Play)'** 버튼을 누르면 AI 가이드의 목소리가 들립니다.
  - **속도 조절**: 음성이 너무 빠르거나 느리다면 **'속도(Speed)'** 버튼을 눌러 0.8x부터 2.0x까지 조절하세요.

---

## 🧭 4. 스마트 내비게이션
현재 위치에서 명소까지 가는 가장 빠른 길을 안내합니다.
- **길찾기**: 명소 카드의 **'길안내(Navigate)'** 아이콘을 클릭하세요.
- **앱 선택**: 앱 내장 지도뿐만 아니라 **Google Maps**, **Waze** 등 선호하는 내비게이션 앱으로 즉시 연결됩니다.

---

## 📡 5. 오프라인(No-WiFi) 꿀팁
기항지에서 데이터 로밍이 걱정되시나요?
- **사전 다운로드**: 호텔이나 크루즈 선내 WiFi 연결 시 도시 데이터를 한 번만 열어보세요. (자동으로 캐싱됩니다.)
- **오프라인 투어**: 데이터 연결이 끊겨도 **GPS 신호**만 살아있으면 위치를 추적하여 해당 장소의 설명을 자동으로 들려줍니다.
