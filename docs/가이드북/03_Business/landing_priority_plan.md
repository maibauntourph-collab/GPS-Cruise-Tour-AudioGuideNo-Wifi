# UI 시퀀스 정합성 복구 계획 (StartupDialog -> Magic Landing)

사용자님, 제가 이미지 순서 해석에 실수가 있었습니다! 원래 의도하신 대로 **초기 설정(StartupDialog)**을 가장 먼저 보여주고, 설정이 완료된 후에 **도시 환영(Magic Landing)**이 나타나도록 시퀀스를 완벽하게 복구하겠습니다.

## 🎯 확정된 UI 흐름 (Confirmed Sequence)
1.  **앱 접속 (App Load)**: 초기 설정창(`StartupDialog`)이 즉시 나타납니다.
2.  **설정 완료**: 사용자가 언어와 도시를 선택하고 창을 닫습니다.
3.  **Magic Landing (후속)**: 설정창이 닫힌 직후, 선택한 도시의 아름다운 풍경과 함께 환영 메시지가 나타납니다.
4.  **메인 지도**: 모든 환영 인사가 끝나면 지도가 나타납니다.

## ✅ 기술적 원복 포인트
- `showStartupDialog` 초기값을 다시 `sessionStorage` 기반으로 자동 노출되게 복구.
- `Magic Landing` 트리거 조건에 `!showStartupDialog`를 다시 엄격하게 적용하여 설정 중에 환영 창이 뜨는 현상 방지.
