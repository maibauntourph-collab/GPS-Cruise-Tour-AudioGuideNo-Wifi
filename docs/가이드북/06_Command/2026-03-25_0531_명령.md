# 2026-03-25 05:31 Hardcoding 24 Country Languages in UI

## 작업 개요
- 24개 국가 언어를 UI에 하드코딩하여 다국어 지원 강화.
- 프리미엄 디자인 및 사용자 경험 최적화.

## 추천 에이전트 및 프롬프트
### 추천 에이전트
- **Designer Kim**: 하드코딩되는 다국어 UI의 시각적 요소와 배치, 프리미엄 디자인 총괄.
- **Dodari**: 코드 구조 설계 및 24개 언어 데이터 매핑 로직 지휘.

### 추천 MCP 및 Skill
- **MCP**: `sequential-thinking` (복잡한 매핑 구조 설계), `context7` (i18n 베스트 프랙티스 참조).
- **Skill**: `Designer Kim`, `Dodari`.

