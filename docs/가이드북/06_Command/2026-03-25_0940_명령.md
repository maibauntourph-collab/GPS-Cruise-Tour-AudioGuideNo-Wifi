# 📋 작업 명령서 - 2026-03-25 09:40 (완료 보고)

## 1. 개요
다른 앱으로 전환했을 때(카카오톡, 카메라 등)도 Kenneth Cruise Guide 앱으로 손쉽게 돌아올 수 있는 '플로팅 아이콘(되돌아가기)' 기능 구현을 최종 완료하였습니다.

## 2. 작업 상세 내역 (Dodari & Designer Kim 협업)

### 🌍 PWA 환경을 위한 스마트 브릿지 아키텍처 (Dodari)
- **`useBackgroundReturn.ts` 생성 완료**: React Native의 `SYSTEM_ALERT_WINDOW` 대신, PWA 환경에서 가장 안전하고 확실한 **Web Notification API**를 활용한 커스텀 훅을 개발했습니다.
- **`Home.tsx` 통합**: 오디오를 재생(`handleToggleAudio`)할 때 권한을 자연스럽게 획득합니다. 앱이 백그라운드로 내려가는 순간(`visibilitychange`), 즉각적으로 상단 플로팅 알림 뱃지를 띄워줍니다.
- **알림 터치 시 앱 즉시 복귀**: 사용자가 플로팅 알림 창을 탭하면, 꺼져있던 브라우저가 다시 `window.focus()` 되어 앱 화면을 최상단으로 가져옵니다!

### 🎨 다국어 툴팁 및 프리미엄 메시지 (Designer Kim)
- **24개국 다국어 번역키 추가**: `returnToApp` 번역 데이터를 `translations.ts`에 추가하여, 한국어 사용자에게는 "되돌아가기", 영어 사용자에게는 "Return to App" 등 알맞은 툴팁 텍스트를 제공합니다.
- **앱 아이콘 연동**: PWA 매니페스트에 등록된 고품질 `192x192` 아이콘을 활용해 다른 앱 사용 중에도 우리 앱의 정체성을 잃지 않는 프리미엄 글래스모피즘 알림 디자인을 적용했습니다.
