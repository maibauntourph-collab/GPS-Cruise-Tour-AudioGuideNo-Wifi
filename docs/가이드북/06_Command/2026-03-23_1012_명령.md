# 🚀 작업 진행 사항 (2026-03-23 10:12)

### 1. 24개 국어 자동 번역 파이프라인 구축 (NeonDB 연동)
- **적용 대상:** `/api/landmarks` API 엔드포인트
- **동작 방식:** 사용자가 단일 언어로 장소(Landmark) 정보를 추가하면, 서버 백그라운드에서 즉시 `GPT-4o`가 호출되어 **사전 정의된 24개 언어**로 `name`, `narration`, `description`, `detailedDescription` 속성을 완전 번역. 번역된 JSON은 **NeonDB의 translations 컬럼**에 자동 병합 업데이트 처리.
- **주요 수정 파일:**
  - `server/lib/autoTranslate.ts` (신규 파일: GPT-4o 배치 번역 및 NeonDB 업데이트 역할)
  - `server/routes.ts` (명소 POST API 생성 후 자동 번역 비동기 트리거 삽입)
  - `server/scripts/translate-all-landmarks.ts` (기존 DB 데이터를 한 번에 업데이트할 수 있는 편의용 스크립트 작성)

### 2. 스페인어 선택 시 한국어가 표시되던 언어 로딩 버그 추적 및 파악
- 기존 플로팅 카드의 다국어 구조를 한국어('ko') 중심 조건식에서 벗어나 **25개 전 언어 동적 매핑 체제**로 변경 완료 (`UnifiedFloatingCard.tsx`, `CitySelectTab.tsx` 반영 등)
- 데이터베이스에서도 24개 언어의 온전한 번역본이 동적으로 불러질 수 있도록 준비 완료
