# 🛠️ [전문 에이전트 연합] 추천 프롬프트 라이브러리 (Part 2)

본 문서는 특정 분야에 특화된 5명의 전문 에이전트를 효율적으로 활용하기 위한 가이드입니다.

---

## 🗳️ [에이전트: 쿼리 마스터] - 데이터 장인
**역할:** 데이터 무결성 및 최적화 전문가
> "NeonDB의 landmarks 테이블에서 중복된 좌표 데이터를 찾는 쿼리를 짜주고, 효율적인 검색을 위해 지리적 인덱스(GIST)를 설정하는 DDL을 제안해줘."
> "사용자의 투어 방문 기록(Visited) 통계를 내기 위한 복잡한 JOIN 쿼리를 최적화해줘."

## 🩺 [에이전트: 오토메이션 닥터] - 자동화 대가
**역할:** AI 콘텐츠 생성 및 워크플로우 자동화
> "Unsplash API를 사용해서 특정 도시의 테마 이미지를 자동으로 검색하고 DB의 photo 필드를 업데이트하는 자동화 스크립트를 작성해줘."
> "Wrangler Cron Triggers를 설정해서 매주 월요일 아침에 시스템 상태 보고서를 이메일로 발송하는 자동화 로직을 짜줘."

## 📢 [에이전트: 마케터 송] - 마케팅 천재
**역할:** SNS 최적화 및 SEO 전문가
> "우리 오디오 가이드 앱의 SEO를 위해 메타 태그와 JSON-LD 구조화 데이터를 완벽하게 설계해줘. '로마 가이트', '세부 투어' 키워드가 상위에 노출되어야 해."
> "사용자가 투어를 마치면 인스타그램에 공유하기 딱 좋은 캡션과 해시태그를 자동 생성하는 기능을 제안해줘."

## 💰 [에이전트: 회계 매니저] - 수익 마스터
**역할:** 수익 관리 및 정산 총괄
> "사용자가 구매한 투어 티켓에서 파트너 수익(20%)과 시스템 수수료(5%)를 자동으로 분리해서 별도 테이블에 기록하는 정산 로직을 구현해줘."
> "이번 달 총 매출 현황을 한눈에 볼 수 있는 대시보드 데이터 API를 설계해줘."

## 📝 [에이전트: 스토리텔러 이] - 스토리텔러
**역할:** 콘텐츠 유머 및 내러티브 최적화
> "지금 랜드마크 설명이 너무 딱딱해. 20대 여행객들이 보고 빵 터질 만한 유머러스한 에피소드로 치비타베키아 성벽 이야기를 다시 써줘."
> "오디오 가이드 시작 시 사용자를 로마 황제처럼 대접하는 몰입감 넘치는 오프닝 스크립트를 한국어로 짜줘."
