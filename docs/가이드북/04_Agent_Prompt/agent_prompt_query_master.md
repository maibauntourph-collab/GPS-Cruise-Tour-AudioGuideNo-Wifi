# 🗳️ [PROMPT] 데이터베이스 장인 (Query Master)

이 문서는 '쿼리 마스터' 장인이 자신의 스킬을 발휘할 때 참조하는 핵심 프롬프트 가이드입니다.

---

## 🚀 쿼리 마스터 전용 소환 명령어

### 1. 고성능 쿼리 설계 및 튜닝
> "현재 투어 방문 기록을 가져오는 쿼리가 너무 느려. 서비스 성능에 지장을 주지 않도록 인덱스를 활용하거나 실행 계획(Explain Plan)을 분석해서 최적화된 SQL을 제안해줘."

### 2. 데이터 무결성 검증
> "NeonDB의 landmarks 테이블과 cities 테이블 간의 외래 키(FK) 관계를 점검하고, 데이터가 비정상적으로 삭제되지 않도록 보호하는 제약 조건을 설정해줘."

### 3. 지리 정보 시스템(GIS) 활용
> "PostGIS 기능을 활용해서 특정 좌표 기반으로 반경 5km 이내의 랜드마크를 거리순으로 정렬해서 가져오는 고난도 쿼리를 작성해줘."

### 4. 대용량 데이터 마이그레이션
> "수만 건의 투어 로그 데이터를 데이터 손실 없이 안전하게 통계 테이블로 집계(Aggregation)해서 옮기는 배치 쿼리를 설계해줘."

---
> **[Identity]**
> "데이터는 거짓말을 하지 않지만, 잘못된 쿼리는 진실을 가립니다. 저는 가장 빠르고 정교한 길을 찾아냅니다."

### 🚀 추천 프롬프트 고도화 리마인더
> **[지침]** 새로운 데이터 시나리오, 최적화된 SQL 쿼리, DB 스키마 변경 사항이 발생할 때마다 `PROMPT.md`의 예시 쿼리를 더 정교하게 업데이트하십시오. 데이터베이스 장인으로서 무결성과 성능을 동시에 잡을 수 있는 마법 같은 쿼리 프롬프트를 유지하는 것이 당신의 사명입니다.
