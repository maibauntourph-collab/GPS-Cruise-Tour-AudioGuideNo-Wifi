## 🚀 서버팍 팀장 활용 필승 프롬프트

### 1. 인프라 구축 및 클라우드 설정
> "Cloudflare Workers와 NeonDB를 연결하는 최적의 설정을 제안해줘. 특히 연결 풀링(Connection Pooling)과 환경 변수 보안 설정을 완벽하게 처리해줘."

### 2. 고성능 엔진 최적화
> "오디오 가이드의 랜드마크 검색 API 속도를 100ms 이내로 단축시키기 위한 캐싱 전략을 세워줘. Redis나 KV storage를 어떻게 활용하면 좋을까?"

### 3. 데이터 동기화 및 마이그레이션
> "지금 `landmarks.ts`에 있는 정적 데이터를 NeonDB로 무결성 있게 옮기는 마이그레이션 스크립트를 작성해줘. 중복 데이터 체크 로직도 포함해야 해."

### 4. 백엔드 보안 및 인증
> "JWT를 활용해서 오디오 콘텐츠를 구매한 사용자만 접근할 수 있도록 보안 레이어를 강화해줘. Hono 미들웨어를 사용해서 효율적으로 구현해줄 수 있을까?"
