
### 교훈

- 큰 컴포넌트(700줄+)에서 복사/붙여넣기 시 중복 선언 주의
- `npm run build`를 커밋 전 반드시 실행하여 컴파일 에러 사전 탐지

## Case 2: 03-22 TTS 언어 매핑 지옥 (High)

### 증상
- 사용자가 **중국어(zh-CN)** 선택
- 화면 텍스트: 중국어로 표시됨 ✅
- TTS 음성: **영어 음성**으로 읽힘 ❌
- zh-TW (번체)도 동일 증상

### 원인

```typescript
// ❌ BEFORE — audioService.ts의 langMap
const langMap = {
  'en': 'en-US',
  'zh': 'zh-CN',    // 'zh'만 있음
  'ko': 'ko-KR',
  // ... 'zh-CN', 'zh-TW' 키가 없음!
};
```

UI에서 전달되는 언어 코드: `'zh-CN'` → langMap에 매칭 없음 → 기본값 `'en-US'` 반환

### 해결

```typescript
// ✅ AFTER — zh-CN, zh-TW 명시적 추가
const langMap = {
  'en': 'en-US',
  'zh': 'zh-CN',
  'zh-CN': 'zh-CN',   // ✅ 추가
  'zh-TW': 'zh-TW',   // ✅ 추가
  'ko': 'ko-KR',
  // ...
};
```

추가 조치 — SSOT(Single Source of Truth) 패턴 적용:
```typescript
// LandmarkDetailDialog.tsx에서 번역 소스를 useLiveTranslation으로 통일
// BEFORE: 여러 곳에서 각자 번역
// AFTER: useLiveTranslation 훅 하나로 통합 → 텍스트와 음성 언어 100% 동기화
```

### 교훈
- 언어 코드는 `'zh'`와 `'zh-CN'`이 **다른 키**임을 주의
- 새 언어 추가 시 langMap, UI, TTS 3곳 모두 확인 필수

## Case 3: 모바일 오디오 자동재생 차단 (High)

### 증상
- iOS Safari에서 랜드마크 근접 시 **TTS 무음**
- 콘솔: `NotAllowedError: The request is not allowed`

### 원인
- 브라우저 Autoplay Policy: 사용자 제스처(터치, 클릭) 없이 오디오 재생 차단
- GPS 기반 자동 트리거는 "사용자 제스처"로 인정되지 않음

### 해결: 3단계 오디오 엔진 잠금 해제

```typescript
// 사용자가 "투어 시작" 버튼을 터치할 때 호출
async unlockAudio() {
  // ① Web Audio API — silent oscillator (하드웨어 채널 점유)
  const ctx = new AudioContext();
  const osc = ctx.createOscillator();
  const gain = ctx.createGain();
  gain.gain.value = 0.0001;
  osc.connect(gain).connect(ctx.destination);
  osc.start(0); osc.stop(0.1);

  // ② Web Speech API — 빈 문장 (volume: 0)
  const utt = new SpeechSynthesisUtterance(' ');
  utt.volume = 0;
  speechSynthesis.speak(utt);

  // ③ HTML5 Audio — 무음 WAV base64
  const audio = new Audio('data:audio/wav;base64,...');
  audio.volume = 0;
  await audio.play();
}
```

### 교훈
- 3가지 오디오 엔진(AudioContext, SpeechSynthesis, HTMLAudioElement)은 **각각** 잠금 해제 필요
- "투어 시작" 같은 **명시적 사용자 제스처** 이벤트 핸들러 내에서 호출해야 함
- Android Chrome은 비교적 관대하지만, iOS Safari는 엄격

## Case 4: Safari TTS 15초 타임아웃 (Medium)

### 증상
- 긴 랜드마크 설명(300자+) 읽기 중 **15초 후 갑자기 멈춤**
- Chrome에서는 정상 작동

### 원인
- Safari/WebKit의 `SpeechSynthesis` 구현에 15초 타임아웃 존재
- Chrome은 이 제한 없음

### 해결: 10초마다 pause/resume 트릭

```typescript
private keepAlive() {
  if (this.synthesis.speaking && !this.synthesis.paused) {
    // Safari의 내부 타이머를 리셋하는 트릭
    this.synthesis.pause();
    this.synthesis.resume();
    // 10초 후 다시 실행
    this.playbackTimer = setTimeout(() => this.keepAlive(), 10000);
  }
}
```

### 교훈
- **문장별 재생(playSentences)**이 근본적 해결: 각 문장이 15초 미만이므로 타임아웃에 걸리지 않음
- keepAlive는 단일 문장이 긴 경우의 **추가 안전장치**

## Case 5: IndexedDB QuotaExceeded (Medium)

### 증상
- 도시 5개 이상 다운로드 시 **"Download failed"** 에러
- 특히 OpenAI 오디오 사전 다운로드 중 발생

### 원인
- 모바일 브라우저 IndexedDB 할당량: 보통 **전체 저장소의 10%**
- 도시 1개 + 오디오 = 약 50~100MB
- 5개 도시 → 500MB 초과 가능

### 해결

```typescript
// 저장 시 QuotaExceeded 감지
async saveOfflinePackage(packageData, etag) {
  // ...
  .catch(error => {
    if (error.name === 'QuotaExceededError') {
      throw new Error('STORAGE_QUOTA_EXCEEDED');
    }
    throw error;
  });
}

// UI에서 안내
if (message === 'STORAGE_QUOTA_EXCEEDED') {
  // "저장 공간이 부족합니다. 방문 완료한 도시를 삭제해주세요."
  showStorageAlert();
}

// 도시 데이터 삭제 (공간 확보)
async deleteCityData(cityId: string) {
  // cities, landmarks, metadata 3개 스토어에서 일괄 삭제
  // cursor를 사용하여 해당 cityId의 모든 랜드마크 삭제
}
```

### 교훈
- `navigator.storage.estimate()`로 남은 용량을 **사전 확인** 후 다운로드 시작
- 오디오 사전 다운로드는 선택적으로 (필수 데이터만 먼저)
- 사용자에게 **용량 관리 UI** 제공 (다운로드 도시 목록 + 삭제 기능)

## Case 6: 일시정지 후 TTS 좀비 (Medium)

### 증상
- 일시정지 → 재개 시 TTS가 **speaking: true인데 소리 안 남**
- 특히 문장별 재생 모드에서 빈번 발생

### 원인
- 일부 브라우저에서 `synthesis.resume()`만으로 복구 불가
- 내부적으로 speaking 상태지만 실제 오디오 출력이 멈춤 (좀비 상태)

### 해결: Watchdog 패턴

```typescript
// resume() 호출 200ms 후 상태 체크
setTimeout(() => {
  if (this.isPausedInternal) return;

  // TTS가 paused 또는 not speaking → 좀비!
  if (this.isSentenceMode && (this.synthesis.paused || !this.synthesis.speaking)) {
    console.log('🚑 TTS stalled → Hard Reset');
    this.synthesis.cancel();
    // 100ms 후 현재 문장부터 다시 시작
    setTimeout(() => this.speakCurrentSentence(), 100);
  }

  // OpenAI/MP3 오디오도 체크
  if (this.audioElement?.paused) {
    this.audioElement.play().catch(e => console.error('Kickstart failed'));
  }
}, 200);
```

### 교훈
- 브라우저 TTS API는 **상태 관리가 불완전** — 자체 감시 로직 필수
- `cancel()` → 짧은 delay → 다시 시작이 가장 신뢰성 높은 복구 방법
