## 3.1 왜 오프라인이 핵심인가

크루즈 여행객의 현실:
- 기항지 하선 시 **WiFi 제로** (데이터 사막)
- 로밍 비용: 하루 $10~15
- 관광 시간: 평균 **6~8시간** (시간 제한)
- 우리의 약속: **인터넷 없이도 GPS 위치 추적 + 오디오 가이드 + 지도**

해법: **IndexedDB + Service Worker 이중 캐싱 아키텍처**

## 3.2 IndexedDB 스키마 — 6개의 Object Store

```typescript
// client/src/lib/offlineStorage.ts
const DB_NAME = 'gps-audio-guide-offline';
const DB_VERSION = 4; // 버전 4: imageFiles 스토어 추가

// OfflineStorage 클래스의 init() 메서드에서 스키마 정의
request.onupgradeneeded = (event) => {
  const db = (event.target as IDBOpenDBRequest).result;

  // ① cities — 도시 기본 정보
  if (!db.objectStoreNames.contains('cities')) {
    const citiesStore = db.createObjectStore('cities', { keyPath: 'id' });
    citiesStore.createIndex('name', 'name', { unique: false });
  }

  // ② landmarks — 랜드마크 (도시별, 카테고리별 인덱스)
  if (!db.objectStoreNames.contains('landmarks')) {
    const landmarksStore = db.createObjectStore('landmarks', { keyPath: 'id' });
    landmarksStore.createIndex('cityId', 'cityId', { unique: false });
    landmarksStore.createIndex('category', 'category', { unique: false });
  }

  // ③ metadata — 다운로드 메타정보 (ETag, 버전, 날짜)
  if (!db.objectStoreNames.contains('metadata')) {
    db.createObjectStore('metadata', { keyPath: 'cityId' });
  }

  // ④ visitedQueue — 오프라인 방문 기록 큐
  //    온라인 복귀 시 서버로 일괄 동기화
  if (!db.objectStoreNames.contains('visitedQueue')) {
    const queueStore = db.createObjectStore('visitedQueue', {
      keyPath: 'id', autoIncrement: true
    });
    queueStore.createIndex('synced', 'synced', { unique: false });
  }

  // ⑤ audioFiles — TTS/OpenAI 오디오 캐시 (Blob 저장)
  if (!db.objectStoreNames.contains('audioFiles')) {
    const audioStore = db.createObjectStore('audioFiles', { keyPath: 'id' });
    audioStore.createIndex('landmarkId', 'landmarkId', { unique: false });
    audioStore.createIndex('language', 'language', { unique: false });
  }

  // ⑥ imageFiles — 이미지 캐시 (30일 TTL)
  if (!db.objectStoreNames.contains('imageFiles')) {
    const imageStore = db.createObjectStore('imageFiles', { keyPath: 'url' });
    imageStore.createIndex('landmarkId', 'landmarkId', { unique: false });
    imageStore.createIndex('cachedAt', 'cachedAt', { unique: false });
  }
};
```

  language: string;
  audioBlob: Blob;         // 실제 오디오 바이너리

  sizeBytes: number;

  cachedAt: string;
}

// 이미지 캐시 항목
interface CachedImage {
  url: string;             // keyPath — 원본 URL이 곧 기본키
  blob: Blob;
  landmarkId?: string;
  cachedAt: string;        // 30일 후 stale 판정
}

## 3.3 오프라인 패키지 저장 — 트랜잭션 설계

```typescript
async saveOfflinePackage(packageData: OfflinePackage, etag?: string): Promise<void> {
  const db = await this.ensureDb();

  return new Promise<void>((resolve, reject) => {
    // [핵심] 3개 스토어에 걸친 단일 트랜잭션
    // → 하나라도 실패하면 전체 롤백 (데이터 정합성 보장)
    const transaction = db.transaction(
      ['cities', 'landmarks', 'metadata'],
      'readwrite'
    );

    transaction.onerror = () => reject(transaction.error);
    transaction.oncomplete = () => {
      console.log(`Saved offline package: ${packageData.landmarks.length} landmarks`);
      resolve();
    };

    // 도시 정보 저장
    transaction.objectStore('cities').put(packageData.city);

    // 모든 랜드마크 일괄 저장 (put = upsert)
    const landmarksStore = transaction.objectStore('landmarks');
    for (const landmark of packageData.landmarks) {
      landmarksStore.put(landmark);
    }

    // 메타데이터 저장 (ETag, 다운로드 시각, 버전)
    transaction.objectStore('metadata').put({
      cityId: packageData.city.id,
      name: packageData.city.name,
      landmarkCount: packageData.landmarks.length,
      downloadedAt: packageData.downloadedAt,
      version: packageData.version,
      etag
    });
  }).catch(error => {
    // [에러 처리] 모바일 브라우저 저장 공간 초과
    if (error.name === 'QuotaExceededError') {
      throw new Error('STORAGE_QUOTA_EXCEEDED');
    }
    throw error;
  });
}
```

## 3.4 useOfflineMode 훅 — 온/오프라인 자동 전환

```typescript
// client/src/hooks/useOfflineMode.ts
export function useOfflineMode() {
  const [isOnline, setIsOnline] = useState(navigator.onLine);
  const [downloadedCities, setDownloadedCities] = useState<CityMetadata[]>([]);

  // ① 네트워크 상태 감시
  useEffect(() => {
    const handleOnline = () => {
      setIsOnline(true);
      syncQueuedVisits();  // 온라인 복귀 → 큐 동기화
    };
    const handleOffline = () => setIsOnline(false);

    window.addEventListener('online', handleOnline);
    window.addEventListener('offline', handleOffline);

    // IndexedDB 초기화
    offlineStorage.init().then(() => loadDownloadedCities());

    return () => {
      window.removeEventListener('online', handleOnline);
      window.removeEventListener('offline', handleOffline);
    };
  }, []);
```

### 핵심 패턴: Online → API, Offline → IndexedDB 폴백

  // ② 데이터 로드 — 온/오프라인 자동 전환

### 도시 다운로드 — ETag + 오디오 사전 캐싱

```typescript
  // ③ 도시 데이터 다운로드 (오프라인 준비)
  const downloadCity = useCallback(async (cityId: string): Promise<boolean> => {
    // ETag 기반 조건부 요청 — 이미 최신이면 304 반환
    const existingMetadata = await offlineStorage.getCityMetadata(cityId);
    const headers: HeadersInit = {};
    if (existingMetadata?.etag) {
      headers['If-None-Match'] = existingMetadata.etag;
    }

    const response = await fetch(`/api/offline-package/${cityId}`, { headers });

    if (response.status === 304) {
      // 이미 최신 버전 — 다운로드 불필요
      return true;
    }

    const packageData: OfflinePackage = await response.json();
    const etag = response.headers.get('ETag') || undefined;

    // IndexedDB에 저장
    await offlineStorage.saveOfflinePackage(packageData, etag);

    // [보너스] OpenAI 오디오도 사전 다운로드
    await preDownloadOpenAIAudio(packageData.landmarks, currentLanguage, (progress) => {
      setDownloadProgress({ cityId, status: 'downloading', message: `Audio: ${progress}%` });
    });
  }, []);
```

### 오프라인 방문 큐 → 온라인 복귀 시 동기화

```typescript
  // ④ 오프라인 방문 기록 동기화
  const syncQueuedVisits = useCallback(async (): Promise<void> => {
    if (!isOnline) return;

    const unsynced = await offlineStorage.getUnsynkedVisits();

    for (const visit of unsynced) {
      const response = await fetch('/api/visited', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({
          landmarkId: visit.landmarkId,
          sessionId: visit.sessionId
        })
      });

      if (response.ok) {
        await offlineStorage.markVisitSynced(visit.id);
      }
    }

    // 동기화 완료된 항목 정리
    await offlineStorage.clearSyncedVisits();
  }, [isOnline]);
```

async isImageStale(url: string): Promise<boolean> {
  const cached = await this.getImage(url);
  if (!cached) return true;
  const REFRESH_DAYS = 30;
  const diff = Date.now() - new Date(cached.cachedAt).getTime();
  return diff > 1000 * 60 * 60 * 24 * REFRESH_DAYS;
}

// 저장 용량 통계
async getImageStorageStats(): Promise<{ count: number; totalSizeBytes: number }> {
  const images = request.result as CachedImage[];
  const totalSizeBytes = images.reduce((sum, img) => sum + (img.blob.size || 0), 0);
  return { count: images.length, totalSizeBytes };
}

### 오디오 사전 다운로드 (useOfflineMode 내부)

```typescript
// 도시 다운로드 시 모든 랜드마크의 OpenAI 오디오를 사전 캐싱
const preDownloadOpenAIAudio = async (landmarks: Landmark[], language: string) => {
  for (const landmark of landmarks) {
    const text = landmark.detailedDescription || landmark.description;
    const sentences = AudioService.splitIntoSentences(text);

    for (const sentence of sentences) {
      const cacheKey = `openai-${language}-${sentence.slice(0, 50)}`;

      // 이미 캐시되어 있으면 건너뛰기
      const existing = await offlineStorage.getAudio(cacheKey, language);
      if (existing) continue;

      // OpenAI TTS API 호출 → 결과를 IndexedDB에 저장
      const response = await fetch('/api/tts/openai/generate', {
        method: 'POST',
        body: JSON.stringify({ text: sentence, language })
      });

      if (response.ok) {
        const audioBlob = await response.blob();
        await offlineStorage.saveAudio({
          landmarkId: cacheKey,
          language,
          audioBlob,
          duration: Math.ceil(sentence.length / 15),
          sizeBytes: audioBlob.size,
          voiceId: 'openai'
        });
      }
    }
  }
};
```

## 3.7 설계 결정과 트레이드오프

### IndexedDB를 선택한 이유
| | localStorage | IndexedDB |
|---|---|---|
| 용량 제한 | **5MB** | **수백 MB ~ GB** |
| 데이터 타입 | 문자열만 | Blob, ArrayBuffer 등 |
| 인덱싱 | 불가 | 인덱스 지원 (cityId별 조회) |
| 트랜잭션 | 없음 | ACID 트랜잭션 |
| → **오디오 Blob + 이미지 Blob 저장 필수** → IndexedDB 선택

### visitedQueue의 `synced` 필드가 number(0/1)인 이유
```typescript
// IndexedDB의 Index는 boolean을 제대로 지원하지 않는 브라우저가 있음
// → 0 (미동기화) / 1 (동기화 완료)로 숫자 사용
synced: 0  // not synced
synced: 1  // synced
```

### QuotaExceeded 처리 전략
```
사용자가 도시 다운로드 시도
  → QuotaExceededError 발생
    → 에러를 'STORAGE_QUOTA_EXCEEDED'로 변환
      → UI에서 "저장 공간이 부족합니다. 불필요한 도시를 삭제해주세요" 안내
        → deleteCity()로 공간 확보 후 재시도
```
