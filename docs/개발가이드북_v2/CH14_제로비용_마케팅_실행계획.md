### 1.1 크루즈 커뮤니티 가치 제공 (무료, 가장 효과적)

**규칙: 절대 광고하지 않는다. 유용한 정보만 제공한다.**

| **Reddit r/cruise** | 질문에 유용한 답변 | "크루즈에서 WiFi 없이 내비게이션 하는 법" 상세 답변 + 앱 자연 언급 |
| **Reddit r/travel** | 기항지 팁 공유 | "Shore excursion 없이 기항지 즐기는 법" |
| **네이버 카페 (크루즈)** | 기항지 자유관광 후기 형식 | "지중해 크루즈 바르셀로나 기항, 자유관광 후기 + 사용한 앱" |
| **Facebook 크루즈 그룹** | 팁 공유 | "Tip: GPS works without WiFi! Here's how I navigate ports..." |

**게시 순서:**
```
1주차: Reddit r/cruise에 2-3개 유용한 답변 (앱 언급 없이)
       → 커뮤니티에서 신뢰 구축

2주차: 자체 포스트 1개 게시 (가치 80% + 앱 소개 20%)
       제목: "I built a free offline audio guide for cruise ports —
              would love your feedback"
       → Reddit은 "솔직한 개발자" 스토리를 좋아함
```

**예상 효과:** Reddit 포스트 1개 = 50-500 방문, 좋은 반응 시 1,000+
