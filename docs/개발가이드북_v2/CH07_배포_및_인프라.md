## 7.2 Hono 미들웨어 체인 상세

```typescript
// server/app.ts — 미들웨어 실행 순서

// ① CORS — 모든 요청에 CORS 헤더 추가
app.use("*", cors({
  origin: (origin) => {
    // credentials: true 시 origin은 '*' 불가
    // localhost, workers.dev 허용
    return origin;
  },
  allowMethods: ["GET", "POST", "PUT", "DELETE", "OPTIONS"],
  credentials: true,
  maxAge: 600,  // preflight 캐시 10분
}));

// ② CSP (Content Security Policy) — 보안 헤더
app.use("*", async (c, next) => {
  await next();
  c.header("Content-Security-Policy", [
    // OpenStreetMap 타일 허용
    "img-src 'self' data: https: *.tile.openstreetmap.org",
    // Unsplash 이미지 허용
    "img-src images.unsplash.com",
    // 중국 Amap 지도 허용 (중국 관광객 대응)
    "img-src *.is.autonavi.com *.amap.com",
    // 제휴사 이미지 허용
    "img-src *.getyourguide.com *.viator.com *.klook.com",
    // Service Worker blob: 허용
    "worker-src 'self' blob:",
  ].join("; "));
});

// ③ Logger
app.use("*", logger());

// ④ Session — CookieStore, 24시간, httpOnly
app.use("*", async (c, next) => {
  const secret = env.SESSION_SECRET;
  const middleware = sessionMiddleware({
    store: new CookieStore(),
    encryptionKey: secret,
    expireAfterSeconds: 3600 * 24,
    cookieOptions: {
      httpOnly: true,
      secure: env.NODE_ENV === "production",
    },
  });
  return middleware(c, next);
});

// ⑤ Request Timer — 응답 시간 측정
app.use("*", async (c, next) => {
  const start = Date.now();
  await next();
  const ms = Date.now() - start;
  // 로깅...
});
```

## 7.3 데이터 파일 구조 — 6개 지역

```
server/data/
├── cities.ts               # 도시 목록 (이름, 좌표, 국가)
├── landmarks.ts            # 기본 랜드마크
├── landmarks_aegean.ts     # 에게해: 산토리니, 미코노스, 아테네...
├── landmarks_alaska.ts     # 알래스카: 주노, 케치칸, 스캐그웨이...
├── landmarks_asia_plus.ts  # 아시아: 도쿄, 싱가포르, 세부...
├── landmarks_caribbean.ts  # 카리브해: 코수멜, 나소, 세인트마틴...
├── landmarks_eu_boost.ts   # 유럽: 파리, 바르셀로나, 암스테르담...
└── restaurants.ts          # 레스토랑 데이터
```

각 파일은 `InsertLandmark[]` 타입의 배열을 export하며, `server/routes.ts`에서 import하여 DB 동기화(`/api/landmarks/sync`)에 사용합니다.

## 7.4 배포 명령어

```bash

# 프로덕션 빌드

# Cloudflare Workers 배포
```
