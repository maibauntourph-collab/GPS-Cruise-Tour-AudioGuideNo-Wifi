## Part 1: 개요 — 왜 자동 영상인가

```
우리가 가진 것:
├── 40+ 도시 랜드마크 데이터 (이름, 설명, 좌표)
├── OpenAI TTS 오디오 (24개 언어)
├── Viator API 투어 데이터 (이미지, 가격, 평점)
└── 랜드마크 사진 URL

조합하면:
40 cities × 3 templates × 10 languages = 1,200 영상 자동 생성 가능
```

## Part 2: 영상 3종 템플릿

### Template A: 기항지 가이드 Shorts (15-30초, 9:16)

```
Frame 1 (0-3초): 도시 와이드샷 + 이름
  - 배경: 도시 hero image (1080x1920, Ken Burns 줌인)
  - 도시명: Pretendard ExtraBold 96px, #FFFFFF, 중앙
  - 국가명: 36px, #FFFFFF 80%
  - 브랜드: "WiFi 없이 즐기는 오디오 투어" 28px, #E85D36
  - TTS: "{도시}, 크루즈에서 내리면 꼭 가봐야 할 곳!"

Frame 2-4 (3-12초): 랜드마크 3개 (각 3초)
  - 배경: 랜드마크 사진 + 하단 그라디언트
  - 순번 뱃지: #E85D36 원형 72px
  - 이름: Pretendard Bold 56px
  - 설명: 32px, 2줄 max
  - 거리: 📍 "항구에서 {distance}"
  - 전환: 좌→우 슬라이드 + Ken Burns
  - TTS: "첫 번째, {이름}. {한줄 설명}"

Frame 5 (12-15초): CTA
  - 배경: 다크 그라디언트 #1A1A2E
  - 텍스트: "WiFi 없이도, 여행의 즐거움은 멈추지 않습니다"
  - QR 코드: 320x320px, 흰색 배경
  - TTS: "지금 무료로 다운로드하세요!"
```

## Part 3: 기술 아키텍처

### 추천 스택: Canvas API + FFmpeg (하이브리드)

```
도다리+서버팍 최종 평가:

| 항목              | Remotion       | Canvas+FFmpeg  |
|-------------------|---------------|----------------|
| 서버 요구사양      | 2GB+ RAM      | 512MB ✅       |
| 렌더링 속도 (30초)  | 2-5분         | 30-60초 ✅     |
| Fly.io 비용       | $29/월        | $15/월 ✅      |
| 한글 렌더링        | 완벽          | 완벽 (node-canvas) |
| Chromium 필요      | 필수 (무거움)  | 불필요 ✅       |

최종 선택: Canvas + FFmpeg
├── node-canvas로 프레임 렌더링 (한글/다국어 완벽)
├── FFmpeg stdin 파이프로 직접 인코딩 (디스크 I/O 제거)
├── Fly.io shared-cpu-2x ($15/월)에서 안정 작동
└── 영상당 비용: ~$0.02, 생성 시간: ~60초
```

### 파이프라인 아키텍처

```
┌─────────────────────────────────────────────────┐
│                자동 영상 파이프라인               │
│                                                  │
│  ① 데이터 수집 (크론 매일 1회)                    │

│                                                  │
│  ② 스크립트 생성                                  │
│     데이터 → 템플릿 변수 매핑 → TTS 스크립트       │
│     → OpenAI TTS API → 오디오 파일 (.mp3)         │
│                                                  │
│  ③ 영상 렌더링 (Remotion)                         │
│     React 컴포넌트 + 데이터 + 오디오              │

│  ④ 썸네일 생성                                    │
│     동일 Remotion 컴포넌트 → 단일 프레임 캡처      │

│                                                  │
│  ⑤ 메타데이터 생성                                │
│     제목 + 설명 + 해시태그 (언어별 템플릿)          │
│                                                  │
│  ⑥ 업로드 큐                                      │
│     YouTube Data API v3 → TikTok API              │
│     → Instagram Reels API → X Media API           │
│                                                  │
│  ⑦ 성과 추적                                      │
│     조회수, 클릭, 앱 설치 → 대시보드               │
└─────────────────────────────────────────────────┘
```

## Part 4: 업로드 API 상세

| 플랫폼 | API | 인증 | Rate Limit | 스케줄링 |
|---|---|---|---|---|
| **YouTube** | Data API v3 | OAuth2 | 10,000 units/day | 예약 게시 지원 |
| **TikTok** | Content Posting API | OAuth2 | 일 제한 있음 | 직접 구현 필요 |
| **Instagram** | Graph API (Reels) | Facebook OAuth | 시간당 200 요청 | Creator Studio 연동 |
| **X** | Media Upload v1.1 | OAuth1.0a | 일 300 트윗 | 직접 구현 필요 |

### YouTube 업로드 코드 스켈레톤

```typescript
// video-generator/src/upload/youtube.ts
import { google } from 'googleapis';

const youtube = google.youtube('v3');

async function uploadToYouTube(videoPath: string, metadata: VideoMeta) {
  const auth = new google.auth.OAuth2(
    process.env.YOUTUBE_CLIENT_ID,
    process.env.YOUTUBE_CLIENT_SECRET
  );
  auth.setCredentials({ refresh_token: process.env.YOUTUBE_REFRESH_TOKEN });

  const res = await youtube.videos.insert({
    auth,
    part: ['snippet', 'status'],
    requestBody: {
      snippet: {
        title: metadata.title,           // 다국어 제목
        description: metadata.description, // SEO 설명
        tags: metadata.hashtags,
        categoryId: '19',                // 여행 & 이벤트
        defaultLanguage: metadata.language,
      },
      status: {
        privacyStatus: 'public',
        publishAt: metadata.scheduledTime, // 예약 게시
        selfDeclaredMadeForKids: false,
      },
    },
    media: {
      body: fs.createReadStream(videoPath),
    },
  });

  // 썸네일 업로드
  await youtube.thumbnails.set({
    auth,
    videoId: res.data.id,
    media: { body: fs.createReadStream(metadata.thumbnailPath) },
  });

  return res.data.id;
}
```
