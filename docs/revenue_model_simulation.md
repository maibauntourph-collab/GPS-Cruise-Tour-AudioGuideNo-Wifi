## 📑 [Tab 1] 단위 매출 분석 (Unit Economics)

**"상품 1개를 팔았을 때 얼마가 남는가?"**에 대한 분석입니다.

| 구분 (Category) | 항목 (Item) | 금액 (KRW) | 비중 (%) | 비고 |
| :--- | :--- | :--- | :--- | :--- |
| **매출 (Revenue)** | **오디오 가이드 정가** | **20,000** | **100%** | |
| **(-) 할인** | 친구/가이드 코드 할인 | -10,000 | -50% | 필수 할인 정책 적용 시 |
| **= 실 결제액** | **Net Revenue** | **10,000** | **50%** | 실제 들어오는 현금 |
| **(-) 지급 수수료** | **가이드 정산금 (리워드)** | -2,000 | -10% | 결제액의 20% |
| | PG사 결제 수수료 | -300 | -1.5% | 카드사 수수료 (추정) |
| | 서버 트래픽 비용 | -100 | -0.5% | Cloudflare 예상 비용 |
| **= 공헌 이익** | **Contribution Margin** | **7,600** | **38%** | **마진율 76% (매우 높음)** |

**[해설]**
*   할인을 50%나 해줘도, **개당 7,600원의 순수익**이 남습니다. (디지털 재화의 위엄)
*   초기 투자금(270만원)을 회수하려면 **약 355개**만 팔면 됩니다. (크루즈 1척 정원 3,000명의 10%만 사도 달성)

## 📅 [Tab 2] 월별 매출 시뮬레이션 (Monthly Projection)

**가정**: 매월 파트너(가이드/승무원)가 늘어나면서 판매량이 **매달 20%씩 성장**한다고 가정.

| 월 (Month) | 파트너 수 (명) | 월 판매량 (개) | 총 매출액 (A) | 파트너 정산 (B) | 운영비 (C) | **순수익 (A-B-C)** | 누적 수익 |
| :--- | :---: | :---: | :---: | :---: | :---: | :---: | :---: |
| **1개월차** (오픈) | 10 | 100 | 1,000,000 | 200,000 | 100,000 | **700,000** | 700,000 |
| **2개월차** | 15 | 200 | 2,000,000 | 400,000 | 100,000 | **1,500,000** | 2,200,000 |
| **3개월차** (손익분기) | 25 | 400 | 4,000,000 | 800,000 | 150,000 | **3,050,000** | **5,250,000** |
| ... | | | | | | | |
| **6개월차** | 50 | 1,000 | 10,000,000 | 2,000,000 | 300,000 | **7,700,000** | **20,000,000+** |

**[해설]**
*   **3개월차**에 누적 순수익이 500만원을 돌파하며 초기 투자금(270만원)을 **완벽하게 회수**합니다.
*   6개월차에는 월 순수익만 **770만원**이 되는 '연금' 시스템이 완성됩니다.

## 💳 [Tab 3] 크레딧 부채 관리 (Liability Management)

크레딧은 '나중에 줘야 할 돈(부채)'입니다.

| 구분 | 발생 원인 | 적립률 | 유효기간 | 예상 소멸율 (낙전) |
| :--- | :--- | :--- | :--- | :--- |
| **추천 크레딧** | 친구 초대 | 10% | 1년 | **60% 이상** (재구매 안 함) |
| **상점 크레딧** | 식당 결제 | 5% | 6개월 | **40% 이상** |
| **이벤트 크레딧** | 가입 축하 | 정액 | 1개월 | **80% 이상** (미사용) |

**[해설]**
*   대부분의 승객은 크루즈 여행을 **"평생 한 번"** 갑니다.
*   여행이 끝나고 남은 크레딧은 **대부분 소멸(Expire)**됩니다.
*   따라서 장부상 부채로 잡히지만, 실제로는 **회사의 영업외 수익(낙전수입)**으로 돌아옵니다.

## 🏆 종합 요약 (Executive Summary)

1.  **높은 마진율**: 디지털 상품이라 원가가 '0'에 수렴하여 **76%의 마진** 확보.
2.  **빠른 회수**: 단 **3개월(또는 400개 판매)** 만에 본전 회수 가능.
3.  **숨겨진 수익**: 포인트 소멸로 인한 **낙전수입**이 쏠쏠함.
