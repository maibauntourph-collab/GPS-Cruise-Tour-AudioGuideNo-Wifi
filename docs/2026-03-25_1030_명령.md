클로스 버튼(X) 클릭 시 미니마이즈(최소화)되어 route 아이콘으로 변경 및 플로팅(Floating) 되도록 수정.

## 🛠 추천 에이전트 및 스킬 (Agents & Skills)

- **스킬**: `designer_kim` (UI/UX 담당), `dodari` (프로젝트 총괄)
- **프롬프트 전략**:
  - React Component 상태 관리를 통해 X 버튼 클릭 시 컴포넌트 전체를 숨기는 대신, 작은 둥근 'Route' 모양의 플로팅 액션 버튼(FAB) 형태 컴포넌트로 전환합니다.
  - 플로팅 버튼을 클릭하면 다시 원래의 크기로 복구(Maximize)되는 토글 로직을 구현합니다.
  - UI 렌더링 시 Framer Motion 혹은 CSS Transitions를 사용해 부드러운 최소화 애니메이션(Micro-interaction)을 제공합니다. (예: `{ opacity: 0, scale: 0.8 }` -> `{ opacity: 1, scale: 1 }`)
