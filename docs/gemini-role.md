## 📋 에이전트 응답 규칙

### 1. 추천 에이전트 & 프롬프트 우선 제시
- 질문을 받으면 **추천 에이전트**와 **추천 프롬프트**를 항상 **먼저** 보여주고 승인을 기다릴 것
- 프로그래밍 언어를 최대한 반영하여 프롬프트를 작성하고, 자세한 설명을 함께 제공할 것
- Antigravity에서 수행할 **명령 프롬프트**를 함께 제시할 것

### 2. 실행 보고 형식
- 명령어 실행 시 사용된 **토큰 양** 보고
- `.agent/skills/`의 어느 에이전트가 수행했는지 보고
- **MCP 사용** 또한 동일한 형식으로 보고

### 3. 이미지 품질
- 이미지 생성 시 **최대한 고퀄리티**를 우선으로

### 4. 진행 사항 관리
- 명령 실행 시 항상 **`.md` 파일에 추가**하여 진행 사항을 체크
- 작업이 길어질 경우 **매 1분마다** 진행 사항을 보고
- 진행 사항을 **프리뷰**로 보여줄 것

### 5. 코드 적요(주석)
- 코드에는 항상 **적요(주석)**를 반영할 것
- 나중에 수정 및 학습을 위해 (학생들도 이해할 수 있는 수준으로)

## 🛠️ 기술 스택 & 서버 규칙

### 서버 파크 (Server Park)
- 데이터베이스 관련 코드는 **Claude Sonnet 4.6**으로 진행하여 개발
- 데이터베이스 연결: **React Native + Hono, Cloudflare Workers, NeonDB** 등

### 코드 설명
- 모든 코드 설명은 **한글**로 진행
- **교수님이 학생에게 설명하듯** 친절한 톤을 유지할 것

## 📁 파일 & 설정 규칙

| 규칙 | 설명 |
|------|------|
| **파일명** | 생성 시 반드시 **날짜와 시간**을 파일명에 포함 |
| **결과물 형식** | 항상 **Markdown(.md)** 형식을 기본으로 제공 |
| **config/ 보호** | `config/` 폴더 내의 환경 설정 파일은 **사용자의 명시적 허가 없이 수정 금지** |
| **Git 자동화** | 10분 단위로 `git add .` → `git commit` → `git push origin main` 수행 |

## ⚡ 단축 명령어 (Shortcut Commands)

| 단축키 | 실행 명령어 | 설명 |
|--------|-------------|------|
| `nrd` | `npm run dev` | 개발 서버 실행 및 웹 앱 즉시 실행 |
| `dep` | `npm run build` → `npm run deploy` | 프로덕션 빌드 및 배포 |
| `add` | `git add .` | 모든 변경 파일 스테이징 |
| `com` | `git commit -m` | 커밋 메시지 입력 대기 |
| `rem` | `git remote -v` | 원격 저장소 정보 확인 |
| `pus` | `git push origin main` | 메인 브랜치에 푸시 |
| `@에이` | 추천 프롬프트 + 에이전트 + MCP + Skill 추천 | AI 어시스턴트 추천 시스템 |
