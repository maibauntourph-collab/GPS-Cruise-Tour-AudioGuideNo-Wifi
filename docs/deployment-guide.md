# 에러 수정 및 배포 가이드 (By @에이)

교수님, 현재 시스템의 건강 상태를 점검하고 안전하게 배포하기 위한 '어벤져스 팀'을 구성해 드립니다!

## 🤖 추천 에이전트 (Role)

### 1. **@Bug Doctor** (AI 프로그램 디버깅 전문가)
- **역할**: 현재 발생하고 있는 타입 에러(TSC)나 런타임 오류를 추적하고 즉각적인 처방을 내립니다.
- **프롬프트 추천**: "현재 `npm run check` 시 발생하는 모든 타입 에러를 검토하고, 코드의 안정성을 해치지 않는 선에서 수정해줘. 특히 최근 작업한 지도 컴포넌트 근처의 사이드 이펙트를 중점적으로 봐줘."

### 2. **@Server Park** (AI 백엔드 팀장)
- **역할**: Cloudflare Workers 배포 환경을 점검하고, 환경 변수 및 인프라 최적화를 담당합니다.
- **프롬프트 추천**: "수정된 코드가 Cloudflare Workers 환경에서 문제없이 돌아갈 수 있는지 점검하고, `npm run deploy`를 통해 안전하게 배포 프로세스를 진행해줘."

### 3. **@Dodari** (AI 개발부장)
- **역할**: 전체적인 작업의 흐름을 관리하고, 깃 커밋(git commit) 및 푸시(push) 일정을 조율합니다.

## 🛠️ 추천 MCP 및 도구
- **TestSprite**: 배포 전 백엔드 API와 프론트엔드 기능이 정상인지 자동 테스트합니다.
- **wrangler**: Cloudflare 배포를 위한 핵심 도구입니다.

## 📈 진행 사항 체크 (Antigravity용)
```powershell
# 1. npm run check 로 에러 진단
# 2. 발견된 에러 수정 후 git add . & commit
# 3. wrangler deploy 로 배포
```
