# 레스토랑 예약 플랫폼 글로벌 점유율 및 전략 보고서

본 문서는 Kenneth Cruise Guide 앱의 레스토랑 예약 기능 효율을 극대화하기 위해, 기존의 개별 식당 공식 홈페이지 대신 지역별 1위 다이닝 예약 플랫폼으로 일괄 연동하기 위한 시장 조사 결과입니다.

## 1. 지역/도시별 1위 식당 예약 플랫폼 추천

레스토랑 예약 시장은 여행객의 접근성과 실시간 예약 확정 여부가 가장 중요하므로, 각 국가 및 대륙에서 시장을 선도하는 플랫폼을 도입하는 것이 타당합니다.

## 2. 예약 플랫폼 내 "가격 비교" 가능 여부

스카이스캐너나 아고다처럼 "동일한 식당에 대해 여러 플랫폼의 가격을 10원 단위로 비교"하는 메타서치 모델은 외식업계에서 불가능에 가깝습니다. (공급망이 다름)

그러나 플랫폼들은 다음과 같은 **"가성비 판별 및 예산 비교 기능"**을 지원하여 유저의 선택을 돕습니다.
*   **평균 예산별 필터링**: `$`(저렴), `$$`(보통), `$$$`(비쌈) 형태로 1인당 평균 가격대를 직관적으로 노출.
*   **플랫폼 독점 할인**: 특히 유럽의 `TheFork`는 "특정 시간대 예약 시 식사대금 20%~50% 할인" 같은 자체 프로모션이 매우 강력.
*   **세트 메뉴/프로모션 가격 노출**: 단품 가격 비교는 힘들어도, 플랫폼에서 제공하는 "점심 특선 코스 $45" 등의 고정 이벤트 가격을 예약 페이지 내에서 즉시 확인 가능.

## 3. 적용 가이드 (수행 계획)

Kenneth Cruise Guide 앱의 105개 주요 레스토랑 랜드마크의 `reservationUrl` 필드를 위 권장 플랫폼의 동적 검색/예약 URL 로직으로 교체하는 스크립트를 실행하여 데이터베이스를 정비합니다. 이를 통해 사용자는 앱에서 '예약하기' 버튼 하나만 누르면 본인이 있는 나라에서 가장 핫하고 신뢰도 높은 예약 앱 화면으로 바로 진입할 수 있게 됩니다.
