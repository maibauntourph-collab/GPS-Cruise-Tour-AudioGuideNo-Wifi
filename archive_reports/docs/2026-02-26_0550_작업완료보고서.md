## 2. 📋 목록 버튼 가시성 및 탭 강제 전환 (Event Dispatch)
- **파일**: [Home.tsx](file:///e:/GPS-Cruise-Tour-AudioGuideNo-Wifi-1/client/src/pages/Home.tsx), [UnifiedFloatingCard.tsx](file:///e:/GPS-Cruise-Tour-AudioGuideNo-Wifi-1/client/src/components/UnifiedFloatingCard.tsx)
- **문제**: 목록 버튼 클릭 시 카드가 표시되더라도 내부 탭이 다른 곳에 있어 사용자가 혼란을 겪는 문제를 발견했습니다.
- **해결**: 커스텀 이벤트(`force-show-list-tab`)를 발행(Dispatch)하고 수신(Listen)하는 로직을 추가하여, 상단 목록 버튼을 누르면 즉시 카드 하단의 '목록' 탭이 활성화되도록 강제 전환 기능을 구현했습니다.
