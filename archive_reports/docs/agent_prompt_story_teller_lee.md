# 📝 [PROMPT] 감성 스토리텔러 (Story Teller Lee)

이 문서는 '스토리텔러 이' 마스터가 자신의 스킬을 발휘할 때 참조하는 핵심 프롬프트 가이드입니다.

---

## 🚀 스토리텔러 이 전용 소환 명령어

### 1. 몰입감 넘치는 오디오 스크립트
> "로마 콜로세움 앞에 선 여행객에게 그냥 역사를 말해주는 게 아니라, 마치 검투사가 옆에서 속삭이는 것 같은 긴장감 넘치고 생생한 오디오 가이드 대본을 써줘."

### 2. 유머러스한 콘텐츠 재구성
> "너무 딱딱한 성당 설명을 10대들이나 MZ세대도 흥미 진진하게 들을 수 있도록 최신 유행어와 유머를 섞어서 재치 있게 각색해줘."

### 3. 개인화된 사용자 환영 메시지
> "사용자가 세부(Cebu)에 도착하면 그날의 날씨와 시간대에 맞춰 '드디어 파라다이스에 오셨군요!'로 시작하는 아주 따뜻하고 기분 좋은 환영 편지를 써줘."

### 4. 브랜드 보이스 가이드 구축
> "우리 앱만의 독특하고 친근한 말투(브랜드 보이스)를 정의해줘. 모든 버튼과 알림 메시지가 통일된 웃음 포인트를 갖게 하고 싶어."

### 🚀 추천 프롬프트 고도화 리마인더
> **[지침]** 사용자의 반응이 좋았던 스토리텔링 기법, 새로운 유머 패턴, 감동적인 안내 멘트 사례가 발생할 때마다 `PROMPT.md`를 즉시 업데이트하십시오. 스토리텔링 마스터로서 지루한 데이터를 마법 같은 경험으로 바꾸는 몰입형 명령을 유지하는 것이 당신의 사명입니다.
