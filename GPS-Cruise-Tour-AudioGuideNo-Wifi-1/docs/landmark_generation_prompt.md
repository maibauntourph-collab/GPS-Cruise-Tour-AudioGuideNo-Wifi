# 🚀 고품질 데이터 생성 명령 프롬프트 보고서

**작성자:** 서버팍 (백엔드 팀장), 쿼리마스터 (DB 장인)
**대상:** AI 데이터베이스 총괄
**목적:** 랜드마크 및 식당 데이터의 품질 고도화 (300자 이상 설명, 정확한 이미지, 예약 링크 포함)

---

## 👨‍🏫 전문가 의견

### 🛠 서버팍 (백엔드 팀장)
> "현재 생성 시스템의 가장 큰 병목은 데이터의 '깊이'와 '연결성'입니다. 단순한 텍스트 나열이 아니라, 사용자에게 가치를 줄 수 있는 **행동 유도 버튼(예약 링크)**과 **고해상도 시각 자료**가 결합되어야 합니다. 또한, 엔진 최적화 관점에서 이 모든 데이터가 한 번의 API 호출로 무결성 있게 추출되도록 프롬프트를 설계했습니다."

### 💎 쿼리마스터 (DB 장인)
> "데이터 무결성이 최상위 가치입니다. 기존의 하드코딩된 이미지 URL은 서비스의 신뢰도를 떨어뜨립니다. 이번 프롬프트에서는 각 장소에 특화된 `image_prompt`를 강화하고, `reservation_url` 필드를 명시적으로 요청하여 DB 스키마의 잠재력을 100% 활용하도록 구성했습니다. 300자 이상의 `detailed_description`은 사용자에게 진정한 '오디오 투어'의 맛을 느끼게 해줄 것입니다."

---

## 📝 제안하는 AI 명령 프롬프트 (MD300+ 규격)

아래는 Gemini 등 대규모 언어 모델(LLM)에 직접 입력하거나, 자동화 스크립트(`mass_generate_landmarks.ts`)에 적용할 최적화된 프롬프트입니다.

```markdown
당신은 전 세계의 숨겨진 보석을 찾아내는 '럭셔리 트래블 큐레이터'이자 '역사 스토리텔러'입니다.
'${city_name}' 도시의 명소, 식당, 액티비티를 기획해주세요.

### 🎯 생성 가이드라인
1. **깊이 있는 설명 (300자 이상)**:
   - `detailed_description`: 단순 정보가 아닌, 그 장소의 분위기, 방문해야 하는 이유, 숨겨진 팁을 포함하여 최소 300자 이상의 매력적인 문장으로 작성하세요.
   - `narration`: 사용자가 현장에서 듣는 오디오 가이드입니다. 400자 이상의 생생한 현장감(소리, 냄새, 전설 등)을 담으세요.

2. **정확한 이미지 매칭**:
   - `image_prompt`: Unsplash나 생성 AI에서 사용할 수 있는, 해당 장소의 건축적 특징이나 시그니처 메뉴가 포함된 정교한 영어 프롬프트를 작성하세요.

3. **실질적인 정보**:
   - `reservation_url`: 해당 장소가 식당이나 유료 액티비티인 경우, 공식 예약 사이트나 대표적인 예약 플랫폼(OpenTable, TheFork, Klook 등)의 예상 링크 형식을 제공하세요.

### 📊 응답 데이터 구조 (JSON)
{
  "city": "${city_name}",
  "landmarks": [
    {
      "name": "장소의 정확한 명칭",
      "category": "Landmark | Restaurant | Activity | Shopping",
      "lat": 위도(정밀도 소수점 6자리),
      "lng": 경도(정밀도 소수점 6자리),
      "description": "한 문장으로 선사하는 강렬한 첫인상",
      "detailed_description": "300자 이상의 역사적 배경과 트래블 인사이트가 결합된 상세 설명",
      "narration": "400자 이상의 몰입형 오디오 가이드 스크립트",
      "reservation_url": "실제 예약 가능한 URL (없으면 null)",
      "price_range": "가격대 (예: €€, $50-100)",
      "opening_hours": "영업시간 상세 정보",
      "image_prompt": "Specific English prompt for high-quality landscape photo of this place"
    }
  ]
}
```
