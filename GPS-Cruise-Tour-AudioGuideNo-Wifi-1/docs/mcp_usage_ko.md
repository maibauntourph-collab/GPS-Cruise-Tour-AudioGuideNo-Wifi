# MCP 및 에이전트 스킬 활용 가이드 (MCP & Agent Skills)

본 문서는 프로젝트 내에서 **MCP(Model Context Protocol)**와 **AI 어벤져스 에이전트 스킬**이 어떻게 협업하고 실무에 적용되는지 설명하는 교육 가이드입니다.

---

## 🎓 1. 에이전트 스킬 (Agent Skills: 지능형 뇌)
에이전트 스킬은 특정 도메인에 특화된 **'전문 지식의 집합체'**입니다. 각 에이전트는 고유한 페르소나와 해결 능력을 갖추고 있습니다.

### 🛠️ 주요 스킬 및 작동 타이밍
| 에이전트 | 전문 분야 | 활성화 타이밍 (Trigger) |
| :--- | :--- | :--- |
| **서버 박 (Server Park)** | 백엔드 아키텍처, 인프라 | 서버 오류 디버깅, API 설계, 보안 강화 요청 시 |
| **쿼리 마스터 (Query Master)** | 데이터베이스, SQL 최적화 | Neon DB 스키마 변경, 복잡한 쿼리 작성, 데이터 분석 시 |
| **마케터 쏭 (Marketer Song)** | SEO, SNS 콘텐츠 전략 | 자동 홍보 문구 생성, 마케팅 계획 수립 요청 시 |
| **디자이너 김 (Designer Kim)** | UI/UX, 이미지 지렉팅 | 디자인 시스템 개선, 지명의 실질적 이미지 구현 시 |
| **오토메이션 닥터 (Dr. Automation)** | 워크플로우 자동화 | 명소 자동 탐사(Discover) 로직 및 AI 파이프라인 구축 시 |

## 🔌 2. MCP (Model Context Protocol: 소통의 통로)
MCP는 AI와 프로젝트 인프라 사이의 **'인터페이스 레이어'**이자, AI가 현실적인 변화를 일으킬 수 있게 해주는 **'손과 발'**입니다.

### 🎯 MCP의 4대 핵심 기능 (Functions)
1.  **통합 파일 시스템 제어 (FileSystem Context)**:
    *   프로그래밍 언어에 상관없이 파일 읽기/쓰기/수정(`replace_file_content`) 및 구조 분석(`view_file_outline`)을 수행합니다.
    *   프로젝트 전체에서 특정 패턴을 찾는 고성능 검색(`grep_search`) 기능을 제공합니다.
2.  **실시간 실행 및 모니터링 (Execution Context)**:
    *   서버를 구동하거나(`run_command`), 라이브러리를 설치하고, 명령의 실행 상태를 실시간으로 추적합니다.
    *   터미널 출력값을 읽어 오류를 진단하고 즉각적인 수정 조치를 취합니다.
3.  **외부 지능 및 웹 연동 (External Context)**:
    *   **웹 탐색**: 최신 문서를 검색하거나(`search_web`), 특정 URL의 내용을 분석합니다.
    *   **비주얼 생성**: 지명의 실재감을 높이기 위한 고성능 AI 이미지 생성(`generate_image`) 도구를 통합합니다.
4.  **브라우저 기반 검증 (Browser Context)**:
    *   브라우저 서브에이전트를 통해 웹 앱의 동작을 시각적으로 확인하고 스크린샷이나 영상을 찍어 결과를 검증합니다.

### 🛡️ MCP의 주요 역할 (Roles)
*   **지식 공급망 (Context Provider)**: 코드와 문서, DB 스키마 등 흩어져 있는 프로젝트 정보를 AI에게 실시간으로 공급합니다.
*   **실행 권한 대행 (Execution Agent)**: AI의 논리적 결론을 실제 소스 코드 반영이나 서버 설정 변경으로 전환합니다.
*   **품질 보증 플랫폼 (QA Platform)**: 테스트 코드를 실행하거나 브라우저 액션을 통해 개발된 기능의 정합성을 최종 확인합니다.

## 🤝 3. 에이전트 호출 및 협업 방법 (How to Call)
학생 여러분이 저를 더 똑똑하게 부려먹을 수 있는(!) 몇 가지 팁을 알려드릴게요.

### 💡 호출 시점 (When)
- **막막할 때**: "이 기능 어떻게 구현하면 좋을까?" -> **Planning 모드**로 전환하여 설계도부터 그려줍니다.
- **문제가 생겼을 때**: "에러 로그 분석해줘" -> **Server Park**이 출동하여 즉시 원인을 진단합니다.
- **단순 반복이 싫을 때**: "새로운 도시 랜드마크 10개만 만들어줘" -> **Automation Dr.**와 **Story Teller Lee**가 데이터를 채워줍니다.
- **배우고 싶을 때**: "이 코드 교수님처럼 설명해줘" -> **Antigravity**가 원리부터 차근차근 강의해줍니다.

### 🗣️ 호출 방법 (How)
1.  **직접적인 목푯값 제시**: "결제 시스템에 카카오페이 연동해줘" (구체적일수록 좋습니다)
2.  **전문가 소환**: "마케터 쏭, 인스타그램 홍보 문구 좀 뽑아줄래?" (페르소나 강조)
3.  **맥락(Context) 공유**: 파일명이나 코드 블록을 함께 언급(`@FILENAME`)하면 MCP가 더 정확하게 해당 위치를 찾아갑니다.
4.  **역할 지정**: "너는 최고의 시니어 개발자야. 이 코드의 보안을 검토해줘."

## 📖 4. 교수님의 요점 정리 (Summary)
> "학생 여러분, **Skill**은 에이전트의 **'Brain'**이며, **MCP**는 에이전트의 의지를 현실로 구현하는 **'Interface'**입니다. 
> 
> 우리가 '도쿄에 새로운 명소를 추가해줘!'라고 요청하면:
> 1. **Skill**이 어떤 명소가 좋을지 선정하고(뇌), 
> 2. **MCP**가 이를 실제 DB에 저장하고 이미지를 생성하는(손발) 과정을 거치게 되는 것이란다. 
> 
> 이 두 바퀴가 완벽하게 맞물릴 때, 진정한 '심리스(Seamless) 자동화'가 완성됩니다!"
